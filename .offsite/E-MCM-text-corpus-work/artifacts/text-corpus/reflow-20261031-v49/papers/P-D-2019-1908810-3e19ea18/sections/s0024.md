Algorithm 1: Guess Unknown Exits Locations

forall candidates do forall rooms in building do Find the shortest distance to an exits or a candidate exit Find the mean of the shortest path distance for rooms return The candidate that has the smallest sum of shortest path distances

Algorithm 1 guesses that exits exist in rooms that will minimize the average distance to travel. We use the rooms identiﬁed here in Section 4.4 for the agent-based simulation.

3.6 Shortcomings

This an algebraic graph theoretic model does not consider a number of salient realities that aﬄict the Louvre:

• Rooms can only hold so many people; they have a maximum capacity. Not every person can move along the shortest path at the same time.

• This model cannot identify bottlenecks, only security risks. Emergency personnel would be advised to take the same paths as evacuees (backward).

We address these issues with the subsequent model.
