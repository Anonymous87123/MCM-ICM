3.2 Parameter Deﬁnitions

m: Number of the evaluation index;

n: Number of the evaluation object;

yi(k): the kth index value of evaluation object i;

xi(k): the normalized kth index value of evaluation object i;

x0(k): the ideal sequence in Grey Relation Analysis ∆i(k): Absolute difference γ(xi(k), x0(k)): grey relation coefﬁcient qi(k):grey relation depth coefﬁcient wj: the weight of the jth index in the second model(GRA&Maxent) vj: the weight of the jth index in the ﬁrst model(AHP) zj: the comprehensive weight of the jth index Ri: the ith coach’s renewed ranking after the weight is altered Qi: the ith coach’s ranking before the weight is altered.

EI: absolute entropy increment SI: relative entropy increment
