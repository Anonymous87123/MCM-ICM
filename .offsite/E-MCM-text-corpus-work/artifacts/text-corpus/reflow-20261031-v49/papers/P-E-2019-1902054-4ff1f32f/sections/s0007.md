4. The model

To quantify the value of a land use project, framed as ”value” (V), which is mea- sured in monetary terms, we consider original ecological value (E) and inﬂuence from the implementation of this project (I). Also, we assume the value are uniform across the area of the project, therefore all above values are functions of area (A).

V (A) = E(A) + I(A) (1)

To deﬁne the original ecological value E, we use a coeﬃcient set each indicating the monetary value per unit area the chosen land should bring, which can be positive or negative.

• n is the total amount of coeﬃcients.

• A0 is the area of land planned to use.
