6.3 Stability Test

The features are selected before the model is established. In order to measure the stability of the evaluation method, the method of replacing some features is used to find out whether the results are consistent and stable after using the same evaluation method. After substituting some of the features, we find that the results of the model in each domain show a small difference when substituting a few features, but the results change greatly when the an increasing number of features are replaced. It represents that the model has strong stability. At the same time, the feature selected in the model also has a greater effect on theresults.
