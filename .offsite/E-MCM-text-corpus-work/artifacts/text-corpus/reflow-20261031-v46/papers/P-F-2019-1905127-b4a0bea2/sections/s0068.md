5.3 Future Work

In the future, some factors have not been reflected in the model should be considered. We need to use the objective evaluation system to add these factors into the overall analysis framework to enhance the model’s ability of explaining the reality. By calculating a large number of parameters in the supranational currency model, we can analyze the possibility of using a universal, decentralized digital currency in the international trade. We hope to integrate the existing loose models and use the same basic model to analyze the trade- offs about using different currencies between microeconomics and international trade. At the international level, we want to know whether the flat currency will exist a new evolution mechanism.
