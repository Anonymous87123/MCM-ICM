6.2 Weaknesses

At this stage, as there is limited access to linguistic data, we have simplified the model to some extent, for example, assuming the same maximum transfer speed between lan-guages. Before using the gradient descent method to find the optimal combination of parame- ters, a large amount of manual derivations and calculations are required. Moreover, this model has many parameters to fit, so the model’s fitting time is long.
