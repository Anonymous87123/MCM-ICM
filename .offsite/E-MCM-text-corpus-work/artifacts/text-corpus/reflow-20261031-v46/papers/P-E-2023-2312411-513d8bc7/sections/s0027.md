4.2.3 Data Extraction and Processing

According to the evaluation system of light pollution risk level constructed in Model I, we need to determine the data of each index for each evaluation site. A.Geographic Information Data The essential index data for each evaluation site are gathered using geo-visualized information data picture extraction in order to precisely compute the light pollution risk level of each evaluation site. The location data of official observation locations and the data they collected make up the visible geographic information data map.
