2.1 Data Screening

Given that we have 50 years of data in 605 variables of the four states, the original database is quite large. Therefore, we should do data screening according to the in- tegrity and usefulness of the information.We first delete some variables manually, and then we use Cointegration and MDS to further narrow down the variables.

Multiple Dimensional Scaling Multidimensional scaling (MDS) is a means of visualizing the level of similarity of individual cases of a dataset. It refers to a set of related ordination techniques used in information visualization, in particular to display the information contained in a distance matrix.

We then utilize this method to further narrow down the variables.
