5.1.4 Production Function

Finally, we use the production function to describe the relationship between diﬀerent partipants . Using historical data, we give the values of the parameters in the function. Denote participant i’s output as qi. It is a function of technology, talent input and capital input denoted as Ai, ki and li. We use Cobb–Douglas production function to describe this relationship:

i · lβi qi = Aikαi (8) i

where Ai, αi, and βi are all positive constants. The constant αi is then the elasticity of output with respect to capital input, and βi is the elasticity of output with respect to labor input.
