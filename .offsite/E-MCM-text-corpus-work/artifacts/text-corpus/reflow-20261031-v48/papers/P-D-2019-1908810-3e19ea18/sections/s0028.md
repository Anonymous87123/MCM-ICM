4.2 Parameter Settings

Using publicly available data we gather some important information. The number of people entering the Louvre is on average 2,532.83 people/hr for 2017 [6]. We estimate that on average a museum-goer will spend 3 hrs in the Louvre. Thus, we calculate that the average population in the Louvre during opening hours is 7,598.49 people. We estimate the maxi- mum safe capacity of the Louvre, which has a footprint is 72,737m2, is 21,748 people based safety code recommendations. We use these parameters to tune our model.
