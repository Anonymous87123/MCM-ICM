3.5 Unknown Exits

A number of emergency exits from the Louvre are kept from public knowledge; they are not on any publicly available ﬂoor plan. Only the emergency personnel and museum staﬀ known the locations of these exits. However, assuming that the designer of the building desired eﬃcient egress in the event of an emergency, we can expect exits to be placed in locations that minimize the average path length to an exit. We use a ﬂood-ﬁll algorithm to ﬁnd the shortest distance to any exit for every node in the graph.
