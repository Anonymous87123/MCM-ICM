The base rate of ﬂow includes an exponentially down-scaling penalty which accounts for
bumping and/or tripping occurring as the density of the room increases. The penalty term
is analogous to the increased viscosity experienced by non-Newtonian ﬂuids as pressure
increases, which also down-scales the ﬂow.

    The non-negativity function, n(ρu) is a function such that nu(0) = 0 and nu(1) = 1 with
0 ≤ n(ρu) ≤ 1. This ensures that ﬂow from a site with zero density is zero.

    The blocking function, b(ρu) is a function such that bu(0) = 1 and bu(1) = 0 with
0 ≤ n(ρu) ≤ 1. This is important because there cannot be ﬂow into a room that is at max
capacity. The eﬀect of this term on the behavior of the system is analogous to the way
transfer events in the agent-based model are rescheduled when they are blocked.

    To actually analyze the densities in particular rooms we use linear algebra and our
graph structure to solve for the change in density of each room at 1 second intervals until
the evacuation is complete.

    Plotting the density distribution of all rooms after some time shows that a room is either
bottlenecked, when ρ = 1, unoccupied, when ρ = 0, or at equilibrium. We deﬁne a room to
be at equilibrium if 0.1 < ρ < 0.9.
