      3.1.3 Initial Value
      The number of native Russian speakers is special. The path towards the equilibrium point is more sensitive
      than other models towards the initial value, for which we have to analyze the sensitivity of its initial value.




                            Figure 13: Sensitivity Analysis on Initial Value of N for Russian Model

      value fluctuates within the range of 20 million, which have little effect on the prediction. So, the Russian
      model is available, the number of native speakers in the next 50 years will be stable between 108 million
      and 120 million
