     For each review instance at a time stamp, we ﬁrst feed the review text (combining both review
     headline and review body) into the embedding system to generate the sentence embedding 𝑣 𝑠 which
     is represented as a 200-dimension vector. Then we generate the input vector 𝑣 𝑖𝑛 𝑝𝑢𝑡 for the 2-layer
