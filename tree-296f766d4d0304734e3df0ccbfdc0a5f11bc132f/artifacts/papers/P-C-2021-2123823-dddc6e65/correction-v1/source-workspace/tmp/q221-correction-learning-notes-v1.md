## 1. “For one thing / For another”不是两个任意优点的装饰

来源为物理第10页 CNN 数据预处理正文及脚注b、c。正文先给负类与正类数量的悬殊，脚注补出已经试过全量训练、预测却一律落在负类的实际失败。随后两条并列动作分别改变同一个失衡问题的两端：增加正类、减少负类。这不是列两个同义理由，也不是一上来介绍CNN的通用优点。两条动作各有执行细节：翻转和外部图片扩充、随机负类抽样。脚注c又明确说缩放、归一化也做了，只因不增加正类数量而未进入这段主线。

值得学的是作者有选择地安排详略：本段论证的是样本数量，常规预处理被放在脚注，失败试验也以短脚注保留。不能因为脚注不在正文就判定没有预处理；也不能把脚注内容都升级为同等篇幅的小节。句式抽象为“具体失衡/失败 → 两个作用方向 → 每一方向的实际操作 → 新样本状态 → 训练接口”。

迁移槽位：失衡对象、实际失败输出、增加端动作、减少端动作、新样本口径。边界：只有确实存在两端干预时才使用成对连接，不应给每一问强塞两条路径。来源里样本总数有冲突，写作动作可以保留，数字必须另行带来源歧义，不能从自然的叙述推导出数据正确。

原创演示（虚构写作场景，不是本论文结果）：

- 电池缺陷样本不足时，保留少数类的不同拍摄角度，同时从正常样本中抽取覆盖主要工况的子集；两项操作分别处理数量不足与冗余。
- 客流记录集中在高峰时段。我们补录低谷时段的观测，并压缩高峰中重复采样的记录，再以站点为单位划分训练与检验数据。

## 2. “What is different here”用来限定借来的模型名

来源为物理第11—13页文本建模。作者先介绍tf-idf的通常含义，接着把本题真正改变的东西落到Lab Status：词不是只按常见或稀少判断，而是要考虑它出现在哪类报告中，再把词级分数聚合为整条备注的分数。原记录把它写成词典/任意类别权重会掩盖这个转折，因为真正的输入是按状态分组的词频，而不是人工挑选的词表。

这里的语言动作不是“采用改进算法提高准确率”，而是“说明常规模型中的一个量 → 指出本题多了哪个标签语义 → 改写该量的定义 → 给出聚合接口”。公式后对权重和均值的解释承担可读性工作，随后才转向四类备注的分布。转折短语只在定义发生变化处有效，不能用来掩饰一个没有实际改动的模型。

迁移槽位：常规量、额外标签/状态、其对贡献方向的影响、新定义、下游聚合对象。边界：论文虽用改进tf-idf命名，不能因此补写没有出现的标准逆文档频率公式。术语、公式和作者的局部改动应分别记录。

原创演示（虚构写作场景）：

- 通常的频次统计不区分投诉是否复核成立；这里保留复核状态，用已确认记录中的出现比例构造词项分数，再汇总到单条工单。
- 普通距离度量默认各方向含义相同，而该测量装置在纵向与横向的分辨率不同，因此先按两个方向的测量误差缩放，再计算样本间距离。

## 3. “Although / Furthermore / In this sense”各自承担不同职责

来源为物理第14页图片与文本融合。第一步承认文本模型单独预测不如CNN；第二步指出它观察的是另一侧面；第三步才授权两者结合。这段先收窄文本模型的地位，再解释它为什么仍值得保留。若压缩成“融合两种模型以提高准确率”，作者公开承认弱项、保留局部价值的判断就消失了。

紧接着出现第二个更局部的转折：两种分数的直方图形状明显不同，作者据此放弃线性组合，转向非线性关系。前一段回答“为什么还保留文本”，后一段回答“为什么以这种形式融合”，不是重复说明融合有益。写作上应保留这两个不同问题的层次，不合并成一个万能理由句。

迁移槽位：已承认的单模型不足、仍保留的信息、可观察分布差异、被放弃的简单形式、实际替换形式。边界：直方图差异只是作者的选型理由，不自动构成线性组合绝对不可用的数学证明。学习这种段落推进，不等于替来源强化论断。

原创演示（虚构写作场景）：

- 短期温度本身不能准确预测负荷，但它能解释历史用电曲线中未被日历因素覆盖的波动，因此保留为补充输入。
- 两个传感器在低浓度区间的响应近似一致，在高浓度区间却出现不同程度的饱和；组合时分别处理这两个区间，不再沿用全范围同一权重。

## 4. “Based on the work above”必须能指出交接对象

来源为物理第15页，第4.3节。这里的“前面的工作”不是紧邻的图片和文本两路原始分数，而是问题(a)的空间传播综合预测和问题(b)的图文融合判断。先把这个指代解析正确，才能理解后面的两个特征、28维映射和正则化逻辑回归。旧记录把两个层次混为一体，会使文章看似顺畅但模型连接错误。

可迁移的组织动作是“前问已交付的两个量 → 同一事件上的对齐 → 新输入向量 → 后问新增运算 → 新决策用途”。过渡句可以很短，因为定义前问输出的工作已经做过；新增内容应集中在对齐、特征扩展和调查优先级，而不是重新介绍前问算法。

迁移槽位：前问产物名称、对象索引、时空或单位对齐、后问新增量、决策用途。边界：只有真实存在的数据接口才能写沿用前文；如果论文没有说明对齐或训练隔离，保留缺口，不能把完整工程实现反推成作者已完成的工作。

原创演示（虚构写作场景）：

- 第一问给出各站的需求分位数，第二问给出可用车辆区间；调度模型按站点和时段对齐这两类结果，再决定车辆转移量。
- 将前一节的结构响应与本节的材料容许值放在同一载荷口径下比较，超出容许值的构件才进入加固候选集。

## 5. “Let us consider a specific example”将规则落到可追踪情景

来源为物理第18—19页更新频率。作者不是只列五个因素就结束，而是给出一个区域的半径、相对GDP、适宜度、起始月份、上次阳性记录以及随后六个月的情景假设。此前的静态评分、季节评分、事件持续时间和负面稳定期由此被放进同一条时间线上。例子承担的是“使规则可执行地被理解”，并不承担外部验证。

值得迁移的是先把触发事件和保持不变的量说清，再给随月份变化的结果。读者由此知道夏季增加、冬季降低的来源，而不是只读到一张趋势图。也应保留事件阈值达到后清零的动作，否则模型输出只是一串分数，没有提交报告的时点。

迁移槽位：场景对象、起始状态、未来情景条件、事件持续期、逐期动作。边界：示例表与折线图读数冲突，不能把两者当作已经复现的同一个结果；在正式学习记录中分别绑定图号与数值。写作自然不意味着算例已经自洽。

原创演示（虚构写作场景）：

- 取一座检修前尚可运行的泵站，固定初始水位和来水情景；检修开始后先停用受影响设备，再按剩余能力逐时更新蓄水量。
- 设仓库本周初已有一批临期库存。未来三天需求按同一预测口径给定，先发临期批次，只有累计缺口达到订货阈值时才补货。

## 6. 本轮保真纠正怎样保护文风学习

一是保留真实失败：第10页全量训练退化为全负类，不能改写成未经比较就选择CNN。二是保留局部让步：文本模型较弱仍有补充信息，不把所有方法都写成全面优越。三是保留尺度区分：词、备注、图文报告、两问综合预测是不同层次，承接词所指的对象必须明确。四是保留图表驱动的动作：分布差异改变融合形式，事件时点改变更新节奏。五是保留作者选择的解释位置：脚注可以承担失败或常规预处理，正文不必给所有细节等长段落。

这些是本篇可观察的写法，尚不能据此称为全语料高频规律。后续应与已有29模式逐项匹配、登记新增或补充的occurrence、function、information order、slots、variants、boundary和disposition；没有新增机制时只加强来源说明，不靠重复拆分扩大语言单元数。新演示只用于展示修辞机制，不继承原文的昆虫对象、数值、模型结果或整句措辞。
