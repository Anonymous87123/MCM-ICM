3.7.2   Five Plane Model Comparison
To determine how the number of search planes affects the results, the models were run using
five planes per day instead of one. In effect, this is no different than searching with one plane
for five times the number of days. It makes sense that the same results are found for five
planes as for one plane: the rectangular search is best, closely followed by the two square
