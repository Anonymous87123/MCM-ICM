ğ The purpose of PSM is to match units of observation with similar characteristics
‫ ݼ‬through propensity scores. First, the propensity score, which is the probability of

being in the influence group of a great coach, is estimated for each sample through
ྐ a logistic regression model. In our data, the PSM model is:Equation 14
                               P (greatcoach = 1|X) = logistic(Xβ)                  (13)
ັ where X is the control variable and β is the parameter to be estimated.

The propensity scores were then used to match the ‘treatment group’ with the ‘con-
trol group’. We use the nearest neighbour matching, i.e. we select the control group
unit with the closest propensity score to match with each treatment group unit. Af-
ter matching, we can obtain a set of similar samples that are similar on the control
variables, thus reducing the impact of selection bias.
