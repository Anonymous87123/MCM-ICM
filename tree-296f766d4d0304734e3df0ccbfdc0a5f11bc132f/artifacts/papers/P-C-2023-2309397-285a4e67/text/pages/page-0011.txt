4.2 Defining Quantitative Attributes of Words

⚫ Number of vowel letters (X4)
The number of vowel letters is one of the quantitative attributes of words. By counting
that number for each word, we found that it takes values in [0, 3] (the value is an integer).

⚫ Maximum number of letter repetitions (X5)
A word can be composed of different letters or may contain repeated letters, and the
maximum number of letter repetitions can also be used as a quantitative property of a
word. By counting that number for each word, we found that it takes values in the range
[1,3] (the value is an integer).

⚫ Emotional polarity value (X6)
Each word tends to imply a certain emotional attitude, and we used the SenticNet
emotion dictionary to get the emotional polarity values for 356 words. In that, negative
values represent negative emotions and positive values imply positive emotions.

⚫ Word internal distance (X7)
