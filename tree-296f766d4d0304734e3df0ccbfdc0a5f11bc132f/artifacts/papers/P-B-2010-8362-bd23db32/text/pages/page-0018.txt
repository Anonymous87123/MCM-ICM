    The single most important optimization implemented in our algorithm is caching.
Suppose our search area has N crime scenes. For each point on the mesh we add a
virtual crime scene and then calculate the criminal location probability distribution
over the search area using the N + 1 points. When calculating the new probability
distribution with N +1 points, instead of doing the full calculation, we use the original
distribution for the first N points and combine it with a distribution for only the new
point in a way that maintains normalization. This gives the algorithm a factor of N
speedup.
    Our algorithm is also nearly perfectly parallelizable. By multi-threading the code,
it can be run over a number of cores with a speedup equal to the number of cores
used. This makes running very high resolution calculations practical if a multicore
or computing cluster is available.
