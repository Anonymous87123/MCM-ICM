2.3 Advanced Model
    The limitation of the basic model is mainly because of the data information. Therefore if the
source of the different aspects’ factors that affect the air quality is comprehensive, with the generic
methodology, a more advanced model could be implemented.

2.3.1 Input and Output of Local Network
     Despite the existing factors mentioned in the basic model, the two aspects of factors below can
be taken into consideration: air pollution created by nature including volcanic eruption, dust cloud
etc.; other human activity, such as the amount of mobile vehicle, resource consumption,
overgrazing and a very important one: policy.
