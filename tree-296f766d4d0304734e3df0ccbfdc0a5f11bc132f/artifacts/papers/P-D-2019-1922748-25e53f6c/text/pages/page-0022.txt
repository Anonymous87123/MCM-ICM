9.3.2 Weaknesses

Firstly, the Ford-Fulkerson algorithm has certain limitations. When there is a special case
for each value in the graph, the algorithm will loop indeﬁnitely. However, considering that
we apply the algorithm to the human ﬂow problem, the probability of occurrence in a special
case is almost zero.

    Secondly, the calculation result will occupy a large amount of storage space with the
increase of precision. However, in general buildings, the required storage space is still within
acceptable limits.
