4.1.2 Evaluate Priority Score by EWM

    Now we can develop our SDG Priority Ranking System with the aid of 5 priority indicators. Entropy
Weight Method (EWM) is an objective weighting method. It gives larger weight to the indicators that
provide more information, so that we can distinguish data with more ease. From this point, we set the
Priority Score of Gi to be

  P S(Gi) = µ1 · N E(Gi) + µ2 · W EC(Gi) + µ3 · BC(Gi) + µ4 · SRI(Gi) + µ5 · SM N F (Gi) (21)

where weight index µ1, · · · , µ5 is calculated by EWM.
