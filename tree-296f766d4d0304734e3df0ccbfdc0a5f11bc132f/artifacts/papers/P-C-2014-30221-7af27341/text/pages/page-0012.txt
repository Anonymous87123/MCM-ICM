5.3   Extensions

    So far we have handled the evaluation for influences of researchers and papers, and our
framework and the network essence can be extended for judgment of individuals, universities,
departments, journals, etc. In the academic field, all these terms are mainly comprised of re-
search papers, thus we can continue to adopt the paper-level network spirit. Specifically, we
regard individuals/universities/departments/journals as vertices, and establish a directed ci-
tation graph where i → j means paper from vertex j is cited by some papers from vertex i.
Note that in this case, weights (e.g. number of citations) can be assigned to edges, and self-loop
is permitted here. Furthermore, we can also build the individual-level network, in which some
interpersonal relationships (e.g. co-authoring) play the main role. These citation or co-authoring
data can be obtained from Google Scholar or university websites.
