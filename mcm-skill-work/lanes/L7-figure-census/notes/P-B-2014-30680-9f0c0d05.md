# P-B-2014-30680-9f0c0d05 — distilled rules

- an unnumbered picture is still an exhibit when the prose points at it and nothing else fills the page slot, so the page-2 network is a figure row whose numbering is none and whose caption source is none [caption.numbering]
- a grid whose rules close every cell - a rule under each row and a vertical between each column - is vertical-rules, not booktabs and not boxed, even when the outer box is no heavier than the interior [table.rule_style]
- a table with no number and no caption line still needs a place, and its section comes from the heading that governs the page, not from the nearest heading above the box [place.section_path]
- rows counts every printed row including the header: four columns over five ranks is 6 by 4, not 5 by 4 [table.rows]
- a spread typeset in Cambria and a body typeset in LaTeX can print the same grid design two pages apart; the rule style is a property of the drawing, not of the typesetter [table.cols]
- the numeric column count follows the content of the body cells: a poll table whose body is club names has one numeric column, the rank stub, however many figures the caption mentions [table.numeric_cols]
- a value column that opens '.23' in three cells and '0.23' in eleven is not decimal-aligned, whatever the column looks like at a glance [table.decimal_aligned]
- width is measured against the local text measure: 443.6 pt is 102 % of the 433.1 pt magazine measure but 129 % of the 343.7 pt body measure, and both are full [table.width]
- the nearest heading is not always above the box - on the Figure 2 page the governing section is the one printed above the art, and the heading below it belongs to the next section [place.section_kind]
- a figure reached only by position counts as uncited: no printed number means count 0 and lead_pages null, and the prose pointer goes into the note [mention.count]
- when the prose sends the reader to a figure by name of the form 'is shown in Figure 3', the lead pattern is as-shown-in, and the quoted sentence must survive the page turn intact [mention.lead_sentence]
- a caption that contradicts the sentence which introduces it is recorded as printed and the contradiction goes in the item note; the census does not repair the paper [caption.verbatim]
- an axis title set at the axis terminus, outside the measured box, belongs to the figure but not to the region, so the note has to say where it prints [caption.position]
- printed_numbers is about the axes: a density curve with no ticks and no scale prints no numbers even though its caption argues about a shift [geometry.printed_numbers]
- a force-directed network with no labels and no legend is still node-link-network, raster or vector [geometry.family]
- two panels printed as two numbered figures are two rows with panel_count 1, and a note that names their mate [geometry.panel_count]
