# P-D-2015-38727-eeb1090f — distilled rules

- A radar or spider chart has no member in the fourteen-name family list; file it as other and put the chart type in other_note, rather than calling it line on the strength of the polygons - the axes are radial, not cartesian [geometry.family].
- Radar legends sit to the right of the plot area but inside the chart frame; record legend as outside-right, because the reference is the plot area and not the frame [geometry.legend].
- Radar charts print tick values along one spoke but label no vertex, so printed_numbers is true while data_labels stays false; the two flags are independent [geometry.printed_numbers].
- A caption noun is not a family: 'The Sustainability Index is a visual indicator' describes the quantity on the spokes and does not turn a radar into an index or indicator graphic [caption.verbatim].
- A summary sheet may paste a body figure as a raster copy; count it as its own row with numbering none rather than dropping it as a duplicate or merging it into the numbered original [caption.numbering].
- When a raster floats inside a wrapped paragraph its italic caption is welded into a prose line, so the caption string is a substring of that line and never a printed line of its own [caption.position].
- Caption position is a class property in this paper, not a per-figure choice: every chart caption is below its frame, including the unnumbered summary-sheet chart [caption.position].
- A before/after pair on one radar frame is one row, not two: the two series are encoded twice over, by colour and by dash pattern, so panel_count stays 1 [geometry.panel_count].
- The six parameter tables share one header string and differ only in row count, so a census should record rows per table rather than treat the run as one repeated exhibit [table.rows].
- These tables are boxed, not booktabs: full outer border, a rule under the header, a rule between every body row and three internal vertical separators [table.rule_style].
- Row separation is drawn with rules on white; there is no alternating row shading and no merged cell anywhere in the run, so zebra and merged_cells are both false even though the Rationale cells wrap onto six lines [table.zebra].
- Cells are centred, not decimal-aligned: 0.363, 38.7 and 12 share neither a decimal point nor a right edge, so decimal_aligned is false while the column is still numeric [table.decimal_aligned].
- Two of the four columns hold numbers and two hold prose; counting columns by content type is what makes a 4-column table comparable to the 3-column tables of the same paper [table.numeric_cols].
- An uncaptioned, unnumbered table run carries count 0 with a null first_page, so a later reader can tell 'never referred to' from 'referred to only by the section heading' [mention.count].
- A table titled only by a bold sub-index heading is titled by a printed heading: put that heading in section_path as the innermost label and leave caption_source at none [place.section_path].
- A table title can be orphaned across a page break - 'Environmental' ends one page and its table opens the next under the running head - so the innermost heading is a better table identity than page adjacency [place.page_zone].

### 四个判断

1. **雷达图记 other，不记 line**。三条序列都是闭合折线，但轴是径向而非笛卡尔；把它塞进 `line` 会让后续按族统计失真。族名写入 `other_note`，见 [geometry.family]。
2. **摘要页浮图单独成行，不当重复删掉**。它是正文 Figure 3 的位图副本、没有图号；删除会丢掉「同一图在同篇里以矢量与位图两种形态出现」这一事实，合并又会伪造一个图号。按 [caption.numbering] 记 `none`。
3. **六张参数表逐张成行，标题取加粗子指标名**。六表表头字符串完全相同（Parameter | Current Value | Predicted Value 2035 | Rationale），差别只在行数，若按一次重复展品处理，行数信息全丢。标题就是压在框线上的 18pt 加粗标题，故进 `section_path` 末端，`caption_source` 保持 `none`、`mention.count` 为 0，见 [place.section_path] 与 [mention.count]。
4. **p1 r1 拒绝为表头格式元素**。该区域（0.6% 页面积、1 条矢量线、宽高比 4.07）经裁图确认是摘要页「Team Control Number」下方的印刷队号 38727，属竞赛表格的头部字段，非展品。
