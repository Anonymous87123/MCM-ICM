# P-C-2014-25318-eac62e81 — distilled rules

- a numbered table whose two rules stand 180 pt apart is measured by no region at all, so four of the seven tables in this paper are declared gaps instead of receiving an invented bbox [table.rule_style]
- a grid drawn as two side-by-side blocks inside one ruled frame is one table: cols counts the physical columns and the header band prints twice [table.cols]
- horizontal rules with one full-height centre divider and no side verticals are booktabs, not vertical-rules and not boxed, because no cell is closed [table.rule_style]
- a band of two alternating rows - an ID row over its value row, three times - is six printed rows and one header row, not three rows [table.rows]
- a grid set short of the measure keeps width full: 74 to 88 per cent of the local 419.4 pt measure is a wide table with air around it, and the percentage is named in the note [table.width]
- the measured box is not the exhibit: Table 5's region stops at 564.1 pt while its closing rule prints at 589.6 pt, and the record keeps the measured bbox with the shortfall in the note [table.note_sentence]
- a caption printed above the grid belongs to that grid even when the previous exhibit's caption printed below its art: the side follows the exhibit type, and this paper splits cleanly - figures below, tables above [caption.position]
- a numbered caption that names the wrong subject is recorded as printed and the mismatch goes into the item note; Figure 7 carries Figure 4's caption word for word over a different network [caption.verbatim]
- a 3-D scatter drawn in a dashed perspective box is scatter with three_d isometric, not surface-or-3D, because the axes hold point markers and no mesh [geometry.three_d]
- two panels of the same family print as one row with panel_count 2, and only exhibits whose panels differ in family become composite-panel [geometry.panel_count]
- printed_numbers is about the axes: a scatter whose ticks print 0.5 to 4.5 carries them, while the illustration that follows has no scale at all [geometry.printed_numbers]
- an exhibit the prose never numbers is still a row when it fills the page slot - Figure 5 is introduced as 'the equation above' and Figure 11 as nothing at all [mention.count]
- a figure cited a page or two BEFORE it prints carries a negative lead_pages, and the value is the exhibit page minus the citing page, never an absolute [mention.lead_pages]
- a heading printed below the art can still govern the page, but here every path is the printed label of the heading that actually governs the region, so section_numbered is true throughout except the unnumbered reference list [place.section_numbered]
- a legend pasted into the plot area counts as legend inside, and an annotation box with an arrow is not a legend: Figure 6 keys nothing and carries legend none [geometry.legend]
