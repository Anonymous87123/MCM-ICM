# P-A-2022-2207343-9469a4fe — distilled rules

- Every figure carries its caption below the frame and every table carries it above the header row, except the three figures whose caption opens the page and sits over a page-top exhibit [caption.position].
- The dominant family is the line plot: power, force, sensitivity and time curves are all drawn as line series with the legend placed inside the plot area [geometry.family] [geometry.legend].
- A multi-panel exhibit is laid out as one row of two or three panels, and each panel is a separately measured image region, so the exhibit is recorded once with its panel count and the other panels are excluded as fragments of it [geometry.panel_count] [place.page_order].
- Three-dimensional reading is reserved for the rendered track scene and the extruded track block; no curve panel is ever three-dimensional [geometry.three_d].
- Tables are booktabs, full width and landscape, with exactly one header row and no zebra shading; merged cells appear only where a race label spans its two gender rows [table.rule_style] [table.merged_cells].
- Units are written in a dedicated column or inside the data cells rather than in the header row, except where the header is itself a time window such as 5s or 1min or states the unit of the row [table.units_in_header].
- The citing spelling is lowercase 'fig. N' in the body text, sometimes with a space before the number ('fig .3'), and parenthetical for the shared road-section figures [mention.style].
- Result tables are introduced by a deictic pointer ('the following table', 'the table below') rather than by number, so they carry a mention count without a numbered spelling [mention.count] [mention.style].
- Captions run from a bare title to a full left/middle/right panel legend, and the panel legend is where units, parameter values and the special-section caveat are stated [caption.words] [caption.units] [caption.conditions].
- An unnumbered in-body schematic is recorded with no caption and is reached only by a deictic body pointer, so its mention carries a lead sentence and no style [mention.lead_sentence].

## Which section holds which family

Derived from the 24 numbered/unnumbered body exhibits + 12 tables + 2 appendix sheets
by `place.section_path` (`section_kind` in brackets):

| section | family | what it holds |
| --- | --- | --- |
| 1.1 Restatement of the Problem [introduction] | line | Fig 1, the motivating power curve; one curve, no legend |
| 1.3 Our Work [introduction] | flowchart-or-schematic | Fig 2, the paper-structure diagram; never cited in the text |
| 3 Notations [model] | table-grid | Table 1, a pure symbol table: 7 rows x 3 cols, no numbers |
| 4.1 The Establishment of power profile [model] | table-grid | Tables 2-3, the fitted power profiles, one table per gender, identical 5x7 shape |
| 4.2 The Solution of Power-Duration model [model] | line, table-grid | Fig 3 the model curve fitted against the data points, then Table 4 the three-stage model grid that produced it |
| 5.1-5.3 model build-up [model] | composite-panel, flowchart-or-schematic, map-or-plan-view | Fig 4-6 states/forces in up to three side-by-side panels; the unnumbered p10 route schematic; Fig 7 ramp division map |
| 5.3.2-5.5 result units [result] | line + table-grid, paired | every raced scenario gets one trajectory line plot and one booktabs table of the same numbers, figure first then table |
| 5.4.1-5.4.2, 5.5.2 [result] | photo-or-raster-image, composite-panel | Fig 10-11 satellite/photo views of the course; Fig 12, 16-17, 21, 23 multi-panel detail strips |
| 6.1-6.2 sensitivity [evaluation] | line, composite-panel | Fig 18-20 single-parameter curves, Fig 21 the model-vs-actual overlay; Table 11 compact comparison |
| 7 Further Discussion [evaluation] | flowchart-or-schematic, composite-panel | Fig 22-23, formation schematics for the extension |
| Appendix, unnumbered sheets [appendix] | composite-panel | the two reproduced RIDERMAN guidance sheets; their tables live inside the sheet raster, see below |

Rule: introduction gets structure diagrams and one motivating line plot; model gets
tables of fitted parameters plus the fit curve; result pairs one trajectory figure with
one results table per scenario; evaluation gets dense multi-curve or overlay panels.
Never a bar chart, histogram, box plot or heatmap anywhere in the paper body.

## When the paper goes three-dimensional

Photorealistic and perspective renderings only: Fig 6 (rendered track scene at the
5.3.1 schematic) and Fig 22 (extruded track block). All other body exhibits are flat
2-D. Condition observed: 3-D appears only where the subject is the physical venue or an
obstacle's spatial extent, and the axis frame is then unlabelled, so the panel is read as
a picture, not as a plot.

## Table shape vs data size

- 1 row of data or 2 rows: 2x5 (Table 7, Table 10) — two riders compared within one
  scenario; landscape is dropped and the grid stays half width.
- 3-5 rows: 3x3 to 5x5 (Table 9, Table 8, Table 11) — a whole section's parameters.
- 5 rows with a repeated left label: 5x6 / 5x7 with merged cells (Tables 2-3, Table 5),
  merging only the race-name column that spans the two gender rows.
- 7 rows x 3 cols: the symbol table (Table 1), the only table whose cells are words, not
  numbers, and the only one that is purely column-width.
- Two-row Summary tables on p1 (4x5, 2x4) are unnumbered and uncaptioned: they restate
  problem and result inside the one-page abstract, so they are recorded as tables with
  `caption.words = 0` and no mention.
- Every one of the 11 numbered tables is booktabs, full width, portrait, one header row,
  no zebra, no diagonal header, units in a column not in the header, decimals aligned.

## Caption templates

- Numbered table: `Table N: The <data item> of <scenario/scope>` — 7 words for a bare
  `Table N: The data of section #24-27`, 10-13 words when the scope, the rider set or the
  model name is added. Colons only; never a full stop form.
- Numbered figure: `Figure N: <noun phrase>` — 4-7 words for a single curve (`Figure 1:
  Power curve`, `Figure 7: Ramp division`), 9-14 when the caption also fixes the axes or
  the data, and 17-25 when it carries the panel legend (`Left: ... Right: ...`) plus
  parameter values.
- Panel legend is the caption's last clause, not a separate line: `Left:`, `Middle:`,
  `Right:` labels, used in 8 of the 24 body figures.
- Units and parameter values live in the caption roughly half the time; the axis labels
  carry them otherwise.
- Verbs are present tense and declarative (`shows`, `are shown`); passive voice in 6 of
  the 11 table captions, active in 5; no caption ever states a conclusion.

## Connector-sentence templates

- Lead, the dominant form (24 of 35 body exhibits): `..., as shown in ﬁg. N.` — a clause
  from the body sentence, sometimes mid-sentence (`as shown in ﬁg. 8 (taking a male time
  trial specialist as an example)`), ligature `ﬁ` preserved.
- Lead, deictic form for tables (7 of 11): `..., we get the following table:` /
  `... are shown in the table below:` / `Then get the results shown in the table below:` —
  a colon, the table never spelled by number.
- Lead, left/middle/right form for composites: `... are shown in the left and middle of
  ﬁg. 12.` names the panels it wants read before the figure is seen.
- Lead, numbered-subject form (1): `Figure 19 shows the changes of ...`.
- Trail, after the exhibit: the reading result, not a restatement — `the power curve
  generally slopes downward to the right`, `Section AB is a short uphill, section CD is a
  long uphill` — one clause, states what the exhibit implies.
- Six body exhibits have no lead sentence at all (Fig 2 structure diagram, Fig 7 ramp
  map, Fig 10 finish photo, the two p1 Summary tables, the two appendix sheets): reached
  from the section heading, not from a sentence.

## Declared gaps

- Table 6 (p11) carries a caption in the text layer and has no measured region: it is set
  as plain running text, not as a ruled grid. It is named in the record `note` and absent
  from `tables`.
- Table 4 (p7) used to be in that same list and is now a full table row. The extractor's
  rule-table span stopped at the header band because the wrapped equation rows push the
  closing rule past the gap limit, so a four-row grid measured as thinner than the minimum
  side and was dropped. The 2026-10-23 fig_extract fix extends the span to the next aligned
  page-wide rule; the region is [101.3, 145.3, 510.7, 297.1], rule_table = true. Lesson for
  this lane: a table with display maths in its cells is the likeliest one to go missing,
  and `unaccounted` is the only signal that it did.
- The two appendix sheets (p24, p25) are single opaque raster regions, so each is one
  composite-panel row and the five tables printed inside them cannot be table rows: one
  boxed 4x3 comparison table on p24, and on p25 two boxed comparison tables (3x2, 4x2),
  one horizontal-rule `Ramp | Strategy` table (2x5), and one empty `Turning Statistics`
  template (4 columns, header only). Their grid readings are in the two item notes.
  Recording them as rows would need sub-region bboxes, which `record.py` does not accept;
  the compromise is declared rather than silent.
- Positive check from the read-only audit: all 33 numbered captions in the text layer
  (Figure 1-23, Table 1-12) have a matching record row; the only missing number is the one
  declared no-grid table.
