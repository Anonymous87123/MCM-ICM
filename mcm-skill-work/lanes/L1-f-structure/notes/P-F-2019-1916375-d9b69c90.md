## model-establishment — 3.1 Currency value and the model of exchange (Equation of Exchange) (pp. 7-7, 15 blocks)

`define → route → route → define → derive → derive → define → define → derive → define → define → define → derive → interpret → interpret`

Block 54 is the symbol table (one block, 148 words) and belongs partly to 2.2 and partly here. The chapter's argument is short and its logic is worth stating exactly: total digital currency is fixed while demand grows, so the system must deflate; the authors therefore measure currency value by productivity. MV = PT with M fixed, then sigma_0 = P sigma and sigma = sigma_0 T / M, so value rises with transaction volume and falls with the money stock. Then a closed-economy identity Y = C(Y-T) + I(r) + G is added and combined to give sigma as a function of r, Y and velocity V(t), from which the paper concludes value 'will increase with the growth of the currency and decrease with the acceleration of the currency'. That inference inverts the equation - in sigma = sigma_0 T/M, more transactions raise value and higher velocity (for fixed T) does lower it, but the paper is reading a comparative static off an identity, not solving a model. The last line ('maintaining the stability of the value of the currency is conducive to maintaining the stability of the global monetary system') is the closest the chapter comes to a claim. Note the extraction splits every display equation from its sentence, so blocks 58-67 alternate equation and prose one line at a time.

## model-establishment — 3.1.2-3.2 Stability return R1 and output-growth return R2 (pp. 8-8, 12 blocks)

`derive → define → define → route → derive → derive → define → define → define → define → derive → interpret`

Two returns, each defined by one equation. R1 (stability) is S(sigma,w) = (1-w)(sigma_t - sigma_{t-1})/sigma_{t-1}: the change in currency value, discounted by the degree of acceptance w - so a widely accepted currency's value change counts for less. That functional form is defensible but arbitrary; nothing derives the linear (1-w) weight. R2 (output growth) introduces capital-use efficiency theta = dV/f > 0, then K* = theta K, substitutes into a Cobb-Douglas Y = A K^alpha L^beta to get Y* = theta^alpha Y > Y, and calls the result increasing returns to scale. It is not increasing returns to scale - it is a level effect from higher capital efficiency, and the paper's own equation shows constant returns (alpha + beta = 1). That mislabelling is the clearest technical error in the model chapters, and it matters because R2 feeds the total return in 3.4 through a fixed weight. Blocks 79-84 are symbol definitions interleaved with equations, each its own measured block.

## model-establishment — 3.3 Capital availability R3, short and long term (pp. 9-10, 8 blocks)

`route → interpret → read-figure → read-figure → derive → interpret → derive → interpret`

The shortest of the three returns and the one with the least content. Short term: if a region's rate exceeds the benchmark r*, capital flows in, supply exceeds demand, local rates fall - a correct but entirely verbal supply-demand statement, illustrated by Figure 3 which is never read beyond its caption. Long term: because total digital currency is fixed, rates rise with capital demand, and the central bank can respond by changing velocity - then equation (12) rewrites sigma = sigma_0 Y/(V(t) i) and (13)-(14) restate P = sigma_0 sigma i M and M/P = L(r,Y), concluding that M/P is inversely proportional to r and proportional to Y and that the central bank moves M to M* so that rates fall to the benchmark. The algebra is bookkeeping on the quantity equation; the interesting claim, that a fixed money stock plus a velocity instrument gives the central bank a substitute for open-market operations, is never tested and is exactly the kind of institutional question the paper's regulatory chapter should have taken up.

## model-establishment — 3.4-3.6 Total return, total cost, and the net-income evaluation (pp. 10-13, 21 blocks)

`derive → define → derive → define → route → define → compute → derive → define → define → define → define → define → define → route → compute → compute → derive → define → compute → interpret`

This is the chapter that produces the paper's verdict, and it is almost entirely a fuzzy-evaluation exercise with hand-set numbers. Return: R_T = R1 + R2 + R3, then split by level with weights phi, then three 2x3 membership matrices for individual, nation and global (the entries 0.2/0.8, 0.6/0.4, 1/0 are simply asserted), a weight vector A = (0.45, 0.32, 0.2), and matrix products giving (0.395, 0.605), (0.595, 0.405), (0.785, 0.215) - maximum-membership then yields R_T = 0.395 R_ind + 0.595 R_nat + 0.785 R_glob. Cost: the same construction with C_f (mining and system maintenance) and C_r split into a1 uncontrollable internet, a2 impaired monetary independence, a3 malicious manipulation, three more 2x3 matrices, and products 0.59, 0.81, 0.88. Evaluation: NI = sum of weighted R minus weighted C, with AHP weights 0.1238, 0.2484, 0.0638 on the three returns and 0.3472, 0.0499, 0.1699 on the three risk costs, giving NI_individual, NI_nation, NI_global. Every number in this chain - the matrices, the level weights, the AHP weights - is asserted rather than elicited or estimated, so the 'net income' figures carry no information about the actual system; they are a consistent scale applied to invented inputs. The one substantive claim is embedded in the weights (risk cost weighs most for individuals, least for nations), and its justification is the third assumption, not the data.

## model-establishment — 4 Choices of different countries (4.1 country size, 4.2 abandoning the national currency) (pp. 13-17, 20 blocks)

`route → define → define → derive → read-figure → interpret → interpret → read-figure → interpret → interpret → route → define → define → interpret → route → derive → read-figure → interpret → interpret → interpret`

Two chapters in one heading, and the first is Mundell-Fleming in miniature. Countries are split into large (their interest rate sets the world rate) and small (rate takers), then the open-economy identity Y = C(Y-T) + I(r) + G + NX with NX = S - I(r) = CF(r) gives the loanable-funds diagram. For large countries both I and CF fall with r, so a rate rise contracts Y less than the naive model predicts and the rate settles at a 'desirable' level; for small countries NX = S - I(r) and any excess saving flows abroad. Both conclusions are optimistic and both are asserted from the diagram rather than computed - there is no elasticity, no calibration, and the diagrams in Figures 6 and 7 are never read numerically. 4.2 then brings in the impossible trinity: under the new system capital is mobile and monetary policy is not independent, therefore the exchange rate must be fixed. That inference is correct as stated, and the two cases follow - abandon the currency and accept the fixed peg plus a commodity-basket conversion rate, or keep it and float (r down, CF up, NX = CF, epsilon down). The fixed-rate case gets the sharpest line in the chapter: with reserves limited under a digital system, central-bank intervention is 'close to invalid'. That is the paper's real answer to Task 4, and it is one sentence.

## model-establishment — 5 Imagination of the regulatory mechanism (global, national, individual) (pp. 17-18, 8 blocks)

`route → ext:context → route → define → define → define → ext:claim → read-figure`

The oversight answer to Task 5, built on a single architectural idea: everyone and every institution is a node, and the global central bank is a 'God node' with authority far above the others, with national regulators as secondary super-nodes and individuals as ordinary nodes holding read access to their own history. The design is stated clearly and it is internally consistent, and block 153's contrast with the sovereign system (where central banks issue and regulate, and where regulation is a national monopoly) explains why a new architecture is needed. Two problems are not addressed: the God node is a central point of failure and control in a system whose selling point is decentralisation, and the paper's own feasibility model assumes most countries use the currency as legal tender, so the node's authority is assumed rather than derived. Block 157's individual-level claims - tax evasion easier to detect, bookkeeping gives auditable personal histories - are the concrete benefits and they cut against the privacy motivation in the introduction. Block 158 is a one-sentence confidence claim and block 159 the Figure 10 caption plus the Section 6 heading.

## results — 6 Dynamic analysis (6.1 banking, 6.2 regions, 6.3 international relations) (pp. 18-21, 24 blocks)

`route → route → define → define → define → derive → define → derive → route → read-figure → define → define → derive → derive → derive → compute → interpret → interpret → interpret → interpret → route → ext:context → interpret → interpret`

6.1 is the paper's one genuine dynamic model and it is small enough to check: bank on-balance-sheet profit grows at fixed g before digital currency, then at g(w) with g'(w) < 0 as acceptance w rises; write g(w) = g(1 - w/w_m) so that growth is zero at w = w_m, giving dPr/dt = Pr g (1 - w/w_m). The logistic claim in the abstract is not what the model is - it is a linear decay in acceptance - and the 'programming' referred to in block 175 is never shown. The conclusion, that on-balance-sheet business disappears and banks become investment intermediaries, follows from the assumed functional form and not from data. 6.2's regional analysis reuses the NI expressions, takes partial derivatives of NI with respect to w for each level, and reports a coefficient matrix (0.0326/0.0489/0.0981/0.2520/0.2048 etc.), concluding that the national level gains most and the individual least with a small diminishing effect. Those derivatives are mechanical derivatives of the fuzzy-evaluation formula, so they inherit its invented weights; the paper reads them as economic findings. 6.3 is the most interesting prose and the least model: three schools of international relations (realism, liberalism, constructivism), then the claim that a common technical and legal framework creates a shared identity that reduces confrontation. It is a plausible argument, entirely untested, and it is the only place the paper engages with politics.
