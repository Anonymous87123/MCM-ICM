## assumptions — 2 Assumptions and Notations (2.1 Assumptions, 2.2 Notation) (pp. 3-3, 8 blocks)

`route → route → limit → limit → limit → limit → limit → define`

Five assumptions, all of them standard textbook macro closures rather than modelling choices about digital currency: consumption and saving by households, production and investment by firms, rational utility-maximising consumers, a government that only purchases and taxes, zero depreciation so that GDP, NDP, NI, PI and DPI coincide, and a government objective of growth, employment, price stability and internal/external balance. The zero-depreciation assumption is the one with real consequences, because it makes the national-accounts identities collapse into each other and is what allows the IS derivation to use S = -a + (1-b)Y + (T-G) without a capital-consumption term. Nothing is assumed about how digital currency is held, priced or redeemed - those choices appear later as a 'virtual country' construction in 3.1 rather than as stated assumptions, which means the paper's most contestable premise is introduced as a modelling device, not defended as an assumption. Block 34 tail carries the 2.2 heading and block 35 is a single sentence pointing at Table 1, whose 19 rows occupy blocks 39-57.

## model-establishment — 3 Mathematical model: two development paths and the virtual country (pp. 3-4, 5 blocks)

`route → define → define → define → route`

The chapter opens by reducing the world to two paths: Path I, every central bank refuses digital currency, in which case nothing changes; and Path II, at least one influential central bank accepts it, buying digital currency from the public and selling it to demanders for traditional currency. The whole paper lives on Path II and never returns to Path I, so the dichotomy does no analytic work - it is a rhetorical device that lets the authors say 'the system will be the same as today's' and move on. Blocks 39-57 are Table 1, the parameter list, and it is the paper's only notation: Y, C, I, G, T, X, M, mbar, y, i, m1, m2, u, alpha, beta, L1, L2, Ms, Ms1, Ms2, P, k, h, CA, FA, NX, NF, AX, AM, Pf, e, iw, gamma, n, sigma, phi. The extraction splits the table one or two rows per block because each row is a separate text line, so the 19 blocks are one definition job. Block 58 ends with the plan - analyse the domestic product market, the money market and the foreign exchange market - and with the 3.1 heading.

## model-establishment — 3.1-3.2 Digital Currency System and the money market (micro and macro) (pp. 5-9, 28 blocks)

`read-figure → define → define → route → define → define → define → define → define → define → define → route → define → derive → define → derive → derive → derive → read-figure → define → derive → read-figure → read-figure → interpret → interpret → read-figure → interpret → interpret`

Two half-chapters that do not connect. 3.1 builds the 'virtual country': a mysterious organisation issues a new digital currency, the virtual country's central bank is that organisation, its residents are the holders, the total issue is constant, units are infinitely divisible, and the unit's price in real currency is determined by economic interaction with real countries. That last clause is the paper's central modelling move and it is never formalised - there is no equation for the price, only the assignment of a country label A. 3.2 is a clean textbook derivation and the best-written part of the paper: money supply and demand definitions, Keynes's three motives, then a Lagrange solution of max u = m1^alpha m2^beta subject to mbar = m1 + m2, giving m1 = alpha/(alpha+beta) mbar and m2 = beta/(alpha+beta) mbar. The solution is correct and the interpretation (each motive's share of money demand is its exponent share) is standard. The macro step then writes M = P mbar, Ms = Ms1 + Ms2, L(Y,i) = kY - hi and solves for i = -Ms/(hP) + (k/h)Y, which is right. The weakness is that digital currency enters this chapter only as the second component m2 of the same money stock: alpha and beta are described as depending on 'risk preferences, liquidity preferences' with no digital-currency-specific term, so the derivation would be identical for any second asset. Figures 1-3 are read out loud in blocks 82, 83, 88 - the LM slope and shift rules are stated correctly (flatter when interest sensitivity is higher, flatter when income sensitivity is lower) but they are textbook statements that the figures merely illustrate.

## model-establishment — 3.3-3.4 Domestic product market (IS) and foreign exchange market (FE) (pp. 10-12, 19 blocks)

`route → define → define → define → define → define → derive → read-figure → route → define → define → define → derive → derive → derive → derive → derive → derive → read-figure`

The IS and FE derivations are the paper's cleanest algebra and also the place where digital currency disappears completely. IS: Y = C + I + G + (X-M) = C + S + T, then I = I0 - di + (X-M) and S = -a + (1-b)Y + (T-G), set equal, giving i = [a + I0 + (Gbar - Tbar) + (Xbar - Mbar)]/d - [(1-b)/d]Y - a slope and intercept with every element sourced to a named parameter. FE: B = CA + FA = 0 with CA = NX = X - M and FA = NF = AM - AX, then NX = X0 - m0 - gamma Y + n Pf e and NF = sigma(iw - i) + phi, solved for i = (gamma/sigma)Y + (iw + n Pf e/sigma) - (X0 - m0)/sigma. Both solutions are correct and the FE one is the only equation in the paper that contains the exchange rate e, so it is the only channel through which digital currency could enter the model. It does not: e is the rate between the real country's currency and the virtual country's currency, but the two curves are then drawn and analysed exactly as in a standard Mundell-Fleming diagram, with no term for the size of the digital-currency stock, for substitution between m1 and m2, or for the virtual country's behaviour. Block 109 closes the chapter and carries the 4 Analysis heading.

## model-establishment — 4.1-4.3 Exchange rate institutions: fixed, floating, and the adjustment rules (pp. 12-16, 33 blocks)

Thirty-three coded groups for what is, in substance, a standard comparative-statics chapter on fixed versus floating regimes with digital currency inserted as the foreign asset. The fixed-rate half works through non-sterilised intervention in Situation I (official settlement surplus, domestic currency under appreciation pressure): the central bank buys digital currency and sells domestic currency, Table 2 shows base currency and international reserve assets both rising, and block 118 correctly follows through to the money multiplier. Four shocks are then catalogued - currency holding, domestic spending, trade, and international capital flows - and the answers are qualitative and correctly ordered (limited effect on interest and output under fixed rates, huge effect on internal equilibrium for trade and capital-flow shocks). Block 130 is the one piece of real-world description in the chapter, a 141-word passage on Google Pay, fingerprints and email-address transfers, and it is doing the work that an assumption about digital-currency demand should have done. The floating half is four blocks: appreciation corrects the surplus, FE moves left and IS follows, equilibrium restores. Blocks 133-135 are Tinbergen's rule and Mundell's matching principle, stated correctly and then illustrated with a figure rather than applied. Two blocks are visibly broken: 122 announces 'Fiscal Policy: take the expansionary monetary policy as an example' (a copy-paste of the previous bullet) and gives three figures with no text, and 141 promises a summary table that is only a caption.

## results — 4.4-4.5 Impact effects under floating rates and real-country cases (pp. 18-19, 12 blocks)

`define → interpret → define → interpret → route → route → route → compute → read-figure → route → route → compute`

The application chapter - the only place where numbers meet the model. Sweden is the fixed-rate case and Israel the floating-rate case; both are diagnosed from the same two panels (domestic inflation plus a balance-of-payments deficit), and the prescribed policy differs only in the exchange-rate instrument: Sweden tight monetary plus tight fiscal with the central bank selling domestic currency and buying digital currency, Israel tight monetary with depreciation doing the external adjustment. The diagnosis is plausible for 2019 and the policy assignment is internally consistent with the IS-LM-FE apparatus. What is missing is any data: no inflation rate, no deficit figure, no interest rate, no exchange-rate path is quoted for either country, so 'there are domestic inflation, balance of international payments deficit' is an assertion about a figure the reader is looking at, not a measured fact. The same is true of the curves - the text says the IS and LM curves move left and the equilibrium is restored, but the figure panels are not read for their slopes or magnitudes. Note the numbering slip: block 148 says the countries will achieve balance 'through the use of policy instruments' before any case is presented, and 152 refers to 'Firgue9' (a misspelling that recurs).

## sensitivity-analysis — 5.1 Sensitivity test (ANOVA), 5.2 Robustness test (pp. 19-20, 8 blocks)

`route → read-figure → read-figure → interpret → route → check → check → read-figure`

Both tests are mislabelled, and the mismatch is instructive. The 'sensitivity' test runs a linear regression/ANOVA on the four country cases and concludes that every variable is indispensable, the coefficients are small, so the model does not change significantly when variables fluctuate and is insensitive to outliers. A regression of the model's own outputs on its own inputs cannot test sensitivity to anything: its coefficients are small because the specification is linear and the units are chosen, and small coefficients say nothing about robustness. The 'robustness' test then applies the same procedure to two new countries, Thailand (fixed) and Mexico (floating), gets the same qualitative policy prescription, and calls that confirmation - which is at best a consistency check on the policy-assignment rule, since the rule is what generated the prescription in the first place. The ANOVA tables in Figures 10 and 11 are never read numerically: no F statistic, no p-value, no R-squared appears in the text, so the claim that the models are 'significant enough' is unverifiable from the paper. This is the weakest chapter in an otherwise conventional paper, and it is the only chapter that claims a statistical result.

## strengths-limitations — 6.1 Strengths and weaknesses (pp. 20-21, 7 blocks)

`route → ext:claim → ext:claim → ext:claim → ext:claim → limit → limit`

Five strengths and two weaknesses, all as bullet lists. The strengths are the multi-level micro-to-macro framework, the originality of proposing models 'for analyzing digital currency', applicability under many shocks, applicability to both exchange-rate regimes, and the policy-tool set. The two weaknesses are honest and they are exactly the right ones: the equations are linear and therefore fail to portray some countries' conditions, and only two countries' interaction is considered. The second is a serious limit on a paper whose entire contribution is about international currency competition, and the paper does not say how the two-country FE curve would generalise to N countries. Note the first strength is a claim about architecture and the third and fourth are claims about coverage, while only the second is a claim about content - and that one ('we creatively propose ideas and mathematical models') is the least checkable of the five.

## conclusion — 6.2 Conclusion (pp. 21-23, 1 blocks)

`ext:claim+close:handoff`

One long block that restates the three-market model, repeats the fixed/floating finding, and then adds the paper's only policy proposal that is not in the body: a United Nations-affiliated 'World Digital Money Bank' (WDCB) with a set of regulations, to keep the new banking and macro systems stable. That institution appears in the summary sheet and here, nowhere in the model, and no mechanism is given for how it would set or enforce anything - it is a governance wish attached to a comparative-statics exercise. The conclusion also repeats the R-based claims ('we find that either systems would achieve internal and external equilibrium') without the caveat that the finding is a property of the assumed policy-assignment rule. References begin at block 174 and run to 206, including Appendix A, whose 'Real Data Result' heading is the last block and has no content after it.
