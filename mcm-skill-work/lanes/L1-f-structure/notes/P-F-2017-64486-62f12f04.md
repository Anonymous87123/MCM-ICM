## memo — 1 Policy Recommendation (letter to LIFE) (pp. 2-3, 10 blocks)

`route → route → select → select → select → select → select → select → check+close:limit → select+close:handoff`

The paper opens with its own recommendation letter, ahead of the summary and the contents. It addresses the client by role ('Honored Director of LIFE'), states that the team was hired and has already investigated the client's plans, then runs six headed recommendations, one per block, each with the same shape: what to do, then one modelled reason. Only two of the six carry a number (the $33526 minimum wage, the $40000 parental leave that the model later moves to $50200). The seventh block is a check ('we compare samples ... with randomly added noises') that doubles as a limitation list, and the last block is the closing hope. The letter therefore states the conclusion before any evidence exists, and the rest of the paper is the evidence.

## data-preprocessing — 3 Parameter Definition And Specific Outcomes (pp. 5-9, 18 blocks)

`source → define → define → define → define → define → define → define → define → define → define → source → read-figure → define → compute → derive → compute → compute`

This is where the paper's data and indices are installed. PUMS is introduced as the data source and its one real limitation is stated (no records under 16). Then a three-tier parameter system is defined and each derived index gets a formula with its symbols spelled out: DPI, saving rate, childcare rate, GDP, NDP, EDL, Gini. Three of those formulas carry citations, so the chapter reads as sourced rather than invented. Table 1 is a 60-row parameter list reduced by measurement to six blocks; the AHP weights come right after it as three computed tables (comparison matrix, CR = 0.0043, two weight tables). Note that the weights are the chapter's only real output and they are produced before any model exists.

## data-preprocessing — 4 Population Zero: PUMS Demographics And Immigrants Selection (pp. 9-12, 16 blocks)

`source → define → define → define → define → define → define → derive → derive → check → read-figure → read-figure+close:limit → read-figure → read-figure → read-figure → read-figure`

Selection is written as a criteria list, not as a filter: five bullets each state a ratio (innovators 7:3, skilled 9:1, male-female 1:1, spouses together, no discrimination) and only then does the algorithm ('we classify the candidates and tag them as 4 different types') appear. ## model-establishment — 5 Evolution Model and Dynamic System (pp. 12-16, 27 blocks)

`route → read-figure → read-figure → interpret → route → limit → limit → define → limit → read-figure → limit+close:source → define → define → define → define → define → define → define → compute → read-figure → define → define → read-figure → define → define → define → define`

The simulation core, built system by system (job, education, marriage, birth, migration). Six assumption blocks are limits with a number attached (logistic death at 70, 5% unemployment, $5000 wage floor, 0.15 tax, retirement at 65, $40000 leave), and four of them cite a source for the number, which is unusual for this corpus. The sample result is read at length ('boomer generation I', the population dip, recovery after year 60), so this is one of the few F papers that interprets its own simulation instead of only showing it. Marriage is the only system with a stated mechanism and a probabilistic rule (distance-based probability, greedy pairing), and the birth system is the only one with a fitted function (age-dependent fertility, f(A) normalised to two births). Figure 13/14 captions interleave with the birth text on page 15, so blocks 156-159 are caption fragments inside a paragraph.

## model-establishment — 6 Trade-offs And Social Equilibrium (pp. 16-19, 24 blocks)

`route → ext:claim → define → limit → mechanism → limit → compute → define → define → define → define → read-figure → derive → define → compute → define → read-figure → define → read-figure → interpret → interpret → interpret → read-figure → compute+close:select`

The equilibrium chapter is the paper's argumentative centre. It starts with four policy assumptions, two of which are feedback rules ('if newly born children are below 60, parental leave pay will be raised by 20%'), which is the only self-adaptation in the model. The minimum-wage search is explicitly local ('instead of searching for the global optimum ... near $25000'), the 5-class income ladder is defined, the steady-state transition equations are derived, and a three-objective problem is solved by an elitist genetic algorithm with one quoted solution (Z = 65234, 9848, 33526). The parental-leave half repeats the pattern with an added class P and an arctan birth-response function, and ends with the three 'interesting facts' read as bullets. Every recommendation in the letter traces back to one of these two blocks.

## results — 7 Model's Function For Different Groups (pp. 19-21, 10 blocks)

`route → read-figure → select → define → define → define → route → define → derive → define`

Subgroup analysis, done by reading happiness across age and education (middle-aged and high-school-educated are the least happy) and then selecting three groups: professional, unskilled, unemployed. Each group gets one definition block naming its priority (time off and parental leave versus work hours, disability care, child care and minimum wage), and two new parameters (disability care budget rate, paid leave days) are added mid-chapter. The allocation model is a two-subgroup two-resource nonlinear programme with a penalty coefficient, and the symbol interpretation block is long enough to carry the whole formulation in prose. No allocation is actually computed - the chapter ends at the formulation.

## results — 8 Interpersonal Relationship Network And New Immigrants (pp. 21-22, 13 blocks)

`route → define → define → read-figure → read-figure → define → define → define → define → mechanism → define → define → compare`

The network chapter cites the small-world and scale-free literature before it defines anything, then defines nodes as individuals and edges as any relation except marriage and parenthood. The linkage matrix, degree and average degree are standard; the mechanism block is the paper's only stated causal claim about the network ('individuals who are well-connected ... are in good financial condition, and a society with high average degree is wealthy') and it is an assumption, not a result. The 16-year age gap caused by the minimum age of immigrants is read off Figure 23, and the chapter closes by comparing degree distributions at year 10 and year 100.

## results — 9 Migration Plan Analysis (pp. 22-24, 8 blocks)

`route → read-figure → read-figure → route → route → route → interpret+close:select → read-figure`

Two comparisons, both decided by the same simulation. First, the migration year is swept (years 10/20/30/40/50) and years 10 and 30 win on population and GDP; the explanation is the age gap - immigrants of age 1-15 fill it. Second, 50000 people are moved either in five phases or in one year, and the phased plan wins for two stated reasons (shorter boomer gap, job creation proportional to last year's GDP). This is the paper's clearest example of a policy conclusion derived from a model output rather than asserted, and it is the source of the letter's '10000 every ten years' claim.

## sensitivity-analysis — 10 Robustness Analysis (pp. 24-24, 2 blocks)

`check → compute`

Two blocks: the method (add noise to initial values, 30 independent runs, report mean and standard deviation) and the table of results at 1% noise. The table is the only place in the paper where uncertainty is quantified, and it is quoted without a verdict - no sentence says whether the spread is acceptable, which is why the letter's robustness claim rests on the earlier qualitative check instead.

## strengths-limitations — 11 Strengths and Weaknesses (pp. 24-25, 6 blocks)

`ext:claim → ext:claim → ext:claim → limit → limit → limit`

Four strengths (comprehensive parameter system plus AHP, PUMS-sourced numbers, seven coupled systems, extensibility to other research) and three weaknesses (subjectively chosen parameters, partly generated data so results may not replicate, no job competition so long-run unemployment is wrong). The weakness list is the sharpest in the paper: it retracts both the parameter values and the reusability of the database, and it names a mechanism the model deliberately omits. No weakness is paired with a fix, and the references start inside the last block.
