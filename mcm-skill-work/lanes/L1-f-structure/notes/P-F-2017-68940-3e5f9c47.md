## model-establishment — Model Design and Justification through Characteristics of Population Zero (pp. 6-17, 61 blocks)

`route → define → define → define → define → source → source → define → derive → define → define → define → source → define → compute → derive → compute → define → define → define → read-figure → source → read-figure → source → route → define → define → source → define → read-figure → limit → derive → mechanism → define → source → define → define → derive → mechanism → define → define → define → define → derive → define → derive → compute → define → compute → define → define → compute → mechanism → mechanism → source → compute → read-figure → define → route → limit → limit`

Sixty-one coded blocks, the longest chapter and the one that carries all the mechanics. Reading order is a single agent's life: lifestages, job search with an education ceiling, underemployment and its exit, then the BLS data that generates jobs (22 categories, extrapolated to 2100), the income percentile interpolation, the 2% annual job loss, the stay-at-home-parent table, birth (a fitted fertility function with one trial-and-error constant, k = 0.2653, calibrated to a world birth rate of 2.4), leave, and a gamma-distributed lifespan. Then the macro layer: progressive tax in five brackets, government spending ratios, inflation as two sinusoids with Canada's 1.3% as the anchor, unemployment, MPC 0.9, investment, GDP. The three metrics are the chapter's real payload, and each is calibrated against a US baseline (I = 88384 against a target of 150000; E = 0.0297 against 0.03; Q = 0 on Earth against 3.5). The sigma component of the income metric is reverse-engineered from a Gini of 0.4 through the log-normal conversion, so the metric's peak is chosen to match a real inequality level. Note the metric design argument for replacing Gini outright ('O(n2) ... computationally intensive'), which is the paper's clearest efficiency-over-accuracy trade.

## sensitivity-analysis — Sensitivity Analysis (pp. 21-22, 6 blocks)

`check → check → interpret → check → interpret → interpret+close:limit`

Two tests, both by re-running the model rather than by perturbing parameters. First, six alternative population selections (skewed sex ratios, older population, 50:50 innovators) in a table that measurement shredded into twenty-two fragments because each cell wraps; the verdict block then names what is invariant (unemployment 3-4%, equality about 10, income above 400000) and what is not (growth path, and the 50:50 innovator case, which is the only run called harmful). Second, migration sizes from 10000 to 100000 with random attributes, where the finding is that a random migrant population does better than Population Zero on income. The chapter ends by retracting its own reach: 'infrastructure is not considered in our agent-based model'.

Five strengths and four weaknesses, all as bullets, measured one line per block.
