## 5. Reusable writing action

Give each step of the procedure its own labelled heading, and let that step produce exactly one exhibit and one
number. step1 runs the ADF test and closes with "It can be seen from the table 2 that the time series becomes
stable after the first-order difference" - one table, one verdict (d = 1). step2 states the ACF/PACF rule as
Table 3 and closes with "From this, we can determine the p value and q value respectively" - one table, two
values. step3 closes with the fitted orders, "The ARIMA model of gold is ARIMA(2,1,1) and bitcoin is
ARIMA(2,1,2)". step4 closes with the horizon and the fit, "we use the data of 30 consecutive days as the
training set and the data of the next 3 days as the test set. The moving step of the training set is 3" plus the
two R² values. The figure that opens the section lists those same four steps as four boxes, so the reader has a
map before the walk.

What makes the move reusable is the pairing: a step that ends in a nameable artefact (a table, an order, a
horizon) can be checked by a reader who skipped the derivation, and a reviewer can ask of every step which
number it produced. A procedure written this way is auditable without a rerun, which is exactly what a modelling
section should be.

The failure is at the same joins. Because each step's number is stated only once and never reconciled with the
others, step2's reading (gold level 2 ACF and level 1 PACF) and step3's order (ARIMA(2,1,1)) can contradict each
other for a whole paper, step3's p value can be read backwards, and step4's R² can be quoted from a formula that
has lost its `1 −` - none of the three is catchable inside its own paragraph, only across the steps. The
one-exhibit-one-number discipline buys auditability only if the numbers are also cross-checked.
