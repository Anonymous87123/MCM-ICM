## 5. Reusable writing action

Turn a ranking into a distance-from-ideal argument, so "smaller" carries the ranking claim
instead of an assertion: define the benchmark vector, name the method the metric is borrowed
from, then state the ordering as a consequence.

> "Node with smaller DC(x) value will rank higher in the priority list since DC(x) is the distance from the node to an ideal ’most signiﬁcant’ node."
