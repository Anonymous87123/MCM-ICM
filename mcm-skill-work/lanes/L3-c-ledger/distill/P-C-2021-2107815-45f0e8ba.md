## 5. Reusable writing action

Name the object the model fits, not the object the reader cares about. Unit 36 closes the colony model
with: "It should be noted that since the data given by the topic is the time and place of the eyewitness
event, the propagation and prediction model is fitting and analyzing the eyewitness event rather than the
population itself." The sentence costs one line and buys three things: it tells the reader what the fitted
quantity actually is, it explains why the next validation section has to use positive-ID reports only, and
it sets up the insufficiency that the following section names - "it also shows that it is obviously
insufficient to classify and predict the topic data set only from the perspective of temporal and spatial
communication model." The move is reusable because it converts a modelling limitation into the transition
to the next model, instead of leaving the limitation for the limitations chapter.
