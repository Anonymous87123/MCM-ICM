## 5. Reusable writing action

**Reject the baseline with a number, then name the model that replaces it in the same sentence.** The ARIMA section exists only to be dismissed, and the dismissal is one sentence that carries its own evidence: `The correlation coefficients derived from the prediction are small not close to 1, proving that the use of ARIMA model to predict the number of medals is not ideal, so we use the GSRF swing prediction model to make predictions`. Everything before it is the number that makes the sentence true - `Table 1 Relevant data for predictive models` gives four fits and four coefficients of determination, `ARIMA (2, 0, 2) 0.218`, `ARIMA (2, 1, 1) 0.257`, `ARIMA (1, 1, 0) 0.430` and `ARIMA (1, 1, 0) 0.494` - and the reader can check 0.494 against "not close to 1" without trusting the author.

The action is worth stealing because most modelling papers keep a dead first model as a courtesy section with no verdict. Here the section has a job: it prices the naive approach, prints the price in a table, and spends one sentence converting the price into a decision. The same sentence also does the transition work that a heading would otherwise have to do - the next paragraph opens `First, we need to build a model for predicting the fluctuations in the number of medals for each country`, already inside the replacement.

**What it costs.** The rejection has no threshold: "small not close to 1" is applied to 0.218, 0.257, 0.430 and 0.494 alike, and nothing in the chapter says what coefficient of determination would have counted as large, so the decision is unfalsifiable even though the evidence is not. The replacement is never priced at all: the GSRF model's own quality appears only as residual standard deviations (`Gold Medals 2.908`, `Total Medals 7.123` in Table 7), never as a coefficient of determination comparable to the four just rejected, so the reader cannot tell whether the model that displaced ARIMA is better than it or merely different. And the number that closes the sentence is the wrong statistic for the claim in the next section: the same paragraph style then reports `The correlation coefficient between "great coaches" and the number of medals was calculated to be 0.874`, computed from the product-moment formula printed as equation (14) but called a Spearman coefficient, on two series the chapter never names, one of them the scored medal table (10/6/3/0) - a single high number offered as proof of a mechanism. Rejecting one model with a number only helps if the replacement is measured with the same instrument.
