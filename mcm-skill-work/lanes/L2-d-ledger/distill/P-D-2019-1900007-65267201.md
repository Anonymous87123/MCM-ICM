## 5. Reusable writing action

Name the model with an acronym, state its governing principle in one sentence, defend the
principle with an everyday analogy, then return to the problem in the very next paragraph and
say what the analogy licenses.

> "The philosophy of the 2D Island-Bridge Model (2D-IBM) is dimensionality reduction. Dimensionality reduction is the process of reducing the number of irrelevant variables in order to obtain a set of principal variables which can reﬂect the attributes of the high dimensional object. For example, the sun shines through leaves (high dimension, 3D), casting shadow (low dimension, 2D) on the ground. Despite the dimension of shadow is lower than that of leaves, you can still have a rough idea of the leaves' shape." … "Back to our problem, evacuees move both horizontally and vertically on stairs, which is a 3D motion. Our Dimensionality Reduction Method seeks to planarize the movement on stairs as 2D horizontal motion."

Companion move from unit 20: keep a borrowed algorithm and change only its weight function —
"However, we make some adjustions based on real-world conditions. First, evacuees can only
assess the condition within their visual threshold … Therefore, the weight of all edges within
the deadly zone should be set as inﬁnity."
