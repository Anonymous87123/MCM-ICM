## 5. Reusable writing action

Give each network metric a one-clause intuition before using it, phrased as "a large X means …,
therefore a large X means good teamwork" — the metric then needs no defence later.

> "The largest eigenvalue λ1 of the adjacency matrix A of a network is a measure of the network strength [2]. Empirically, a large λ1 indicates that there are many edges in the network, so the network is highly connected. In the case of passing network, a large λ1 means it is convenient to pass the ball across the team. Therefore, we argue that λ1 is a reflection of teamwork success."

Companion move from unit 17: after estimating a transition matrix, read the dyads straight off
its heatmap instead of describing the matrix — "The estimated transition probability matrix is
shown in Figure 5. From this figure, we find several dyadic configurations: (D10, D3), (M10, D7),
(M7, M1), (M8, D7) and so on."
