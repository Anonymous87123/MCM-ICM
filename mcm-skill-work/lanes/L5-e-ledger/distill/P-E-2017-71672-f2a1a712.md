## 5. Reusable writing action

Give every principle its own metric with an explicitly stated optimal value, and when two
principles measure the same underlying thing, merge them with a named formula from another field
rather than summing them twice.

> "To combine these metrics, we use a modification of the following effectiveness measure, originally intended for use on precision P and retrieval P, two variables which interact [9]." … "We weighted each correlated metric equally, so we set α = 0.5. Because a higher value for each of our principle metrics corresponds to a higher level of success, used only the second term, made positive."

Companion move from unit 8: when the data does not exist, say so and substitute a stated subjective
rating rather than dropping the principle — "We did not find data on the extent that each city is
doing this currently, so we settled on assigning a rating from 0 to 1 based on the stated goals in
their growth plans."
