## 5. Reusable writing action

Build the production ceiling with a learner whose inputs are policy variables, so an intervention is
just a change to an input vector rather than a second model.

> "The implementation of these policies can be reflected on production model because the policies …" … "One thing worth noting is that the increase or decrease is not limitless, we can’t put all emphasis…"

Companion move from unit 4: state each industry's indicator list before any of them is modelled, then
say the same network is reused three times — "The establishment of husbandry production model is
similar to the establish- ment of neural network…" — so the reader learns one method and applies it
three times.
