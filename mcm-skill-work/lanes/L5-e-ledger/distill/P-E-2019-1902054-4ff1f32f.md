## 5. Reusable writing action

Redefine the accounting quantity in the first sentence, then let the model's terms be the named
costs that definition forces — the list of harms becomes the model's structure rather than
background.

> "We deﬁne the true economic cost of land use projects to include and account for their impacts on ecosystem services. The impacts on environmental segments include but are not limited to:" … "To quantify the value of a land use project, framed as ”value” (V), which is mea- sured in monetary terms, we consider original ecological value (E) and inﬂuence from the implementation of this project (I)."

Companion move from unit 14: give a parameter a sign convention so the model can be read before
it is run — "A negative K shows the project is polluting the ecosystem; a positive K indicates the
project is improving the ecosystem, and when K = 0 the project is not aﬀecting the ecological
services of the land."
