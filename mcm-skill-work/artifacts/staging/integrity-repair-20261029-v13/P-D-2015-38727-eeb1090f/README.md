# D38727：作者动作与编辑边界分离纠偏

本代针对真实的文字归因和语气问题纠正7个候选，不增加模式或独立支持，不是重包草稿。41个候选的功能、框架、边界及82个原创例句已由根线程逐项复读。图表蒸馏和公式核验继续暂停，没有正式产物安装或闭环事务。

## 纠偏内容

- 单元003：把可误读为单一总分的aggregation改为component construction；功能只描述作者的分维度呈现与构造交接。“不得发明总分”明确属于使用边界，不再混入作者动作。
- 单元015：原候选把“有意区分演示和普遍验证”写成作者功能，但作者在选取多样案例后实际上声称普遍适用。现在正面动作只保留“选样理由与比较目的”；不能推出普遍有效的限定明确标为编辑护栏，不能冒充作者已经完成的论证。
- 单元024：教育中的服务承诺和交通中的地方配套出资共享“支持附带条件”机制，但不能给匹配出资变体强加服务期限或留才结果。保留教育后段“This condition”的指代歧义，不将所有留才目的归因到单一条款。
- 单元030：框架与两个原创例句显式加入scenario和projected，避免脱离上下文后把情景预测写成已观测改善。旧例句保留在归因审阅的before中，没有抹除。
- 单元036：measured consequence改为analytical consequence，允许后续计算或证据支持的分析后果，不暗示引言已经观测了政策处理效果。
- 单元037：作者动作限定为“用一般认为、影响或相关的说法交代输入关联”；原创例句中额外的因果警戒标为编辑脚手架，不视为原文额外出现的一句话。
- 单元039：执行伙伴限定到具体的公共健康教育活动，不扩写成整个基础设施章节的统一负责人。

这些是文字学习准确性的修正，不是新的公式、数值或事实警戒验收。所有原文见证、页码、章节、候选ID和单篇支持保持不变。
