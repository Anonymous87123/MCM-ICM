# D38727：仅正文的内容交接蒸馏

本代新增的是跨段落、跨章节的论证连接，不是新语言模式，也不是论文关闭记录。图表蒸馏与公式核验均按用户最新答复暂停；没有图片调用、渲染、公式检查、正式分支安装或历史追加。

## 实际成果

[content-handoffs.draft.json](content-handoffs.draft.json) 保存8条内容链、32个带物理页码和文本行号的原文片段。每条链包括相邻环节、连接依据、已有语言单元ID、可迁移的写作动作和适用边界。证据来自v10独立的新鲜PDF文字层，不把历史提取、NFKC预览或文字行号当作版面权威。

1. 案例选择链：数据可得性及演示目的 → 排除复杂条件 → 与案例自身优先级对齐。可学的是选择理由和适用范围一起交代，而非把方便案例当成普遍验证。
2. 教育方案链：诊断中的教育需要 → 四类培养项目 → 资助和服务承诺 → 作者陈述的人才与服务目的。可学的是把建议写到部件、参与条件和服务去向。原文后段的“This condition”指代不够明确，因此不能将全部留才效果单独归因于前面的服务承诺；这里保留的是方案整体的目的交接，不是已验证的因果链。
3. 交通方案链：交通不足的跨部门后果 → 山体滑坡和冬季封路等运行瓶颈 → 道路、桥梁和清雪措施 → 地方配套投入 → 意向性服务收益。修复措施旁保留可行性限定，不把收益清单当实测效果。
4. 卫生基础设施链：城市增长下的卫生需要 → 实施地点和覆盖理由 → 贷款优先标准 → 健康教育活动 → 明确执行伙伴 → 意向性受益。健康工作者和助产士对应教育活动，不被扩写成全部基础设施的负责人。
5. 残余风险链：总体风险叙述较好 → 仍有地震暴露 → 建筑要求 → 意向性安全目标。总体评价与局部动作同时保留，不用总体结论覆盖例外。
6. 未闭合的社会问题链：难民与性别问题 → 不采取措施时的展望 → 教育方案仅明确列出性别平等意向。不能因为同属社会部门就将难民问题也标为已被该方案解决；这只是所读方案正文中的缺口，不推断外部政策不存在。
7. 外部约束链：跨境因素与本地可改善部分分开 → 本地通风要求 → 作者报告的环境例外 → 区域尺度的响应建议。不将本地措施写成外部约束已消失。
8. 方案到展望链：建议 → 部分输入的假设更新与其余固定 → 带例外的展望 → 输入质量边界。这里只追踪接口的文字，没有核对表中数值、公式、图中结果或政策响应函数。
