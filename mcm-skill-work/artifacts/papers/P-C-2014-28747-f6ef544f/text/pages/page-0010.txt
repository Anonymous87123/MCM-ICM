4.2.1   An introduction to PageRank

    Because of its powerful retrieval function and high quality retrieval serviceGoogle is
one of the most popular search engines. Using its PageRank algorithm to calculate the
PageRank values of each web page, Google get the rank of the web page by balancing
the number of links to the search target and the quality of these links. The higher the
value of PageRank is, the higher the rank has[2].
