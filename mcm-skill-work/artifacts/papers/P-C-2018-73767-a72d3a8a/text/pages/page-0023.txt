         9.2     Weaknesses
               • Subjectivity.The calculation of some synthesized variables is subjective. It can
                 cause extra error of our models.

               • Lack necessary data. Lack of data on energy production, we can only use data on
                 energy consumption to replace them.

               • Simplifying assumption.For convenience of modeling, we neglect the elements
                 about import and export, which play import roles in economy.
