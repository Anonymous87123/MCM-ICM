5.2.4 Using K-Means Clustering to Deﬁne Sonic Genres

K-Means is a clustering algorithm used to group data based on similarities. First, a set number of cluster

centroids are instantiated in n-dimensional space, where n corresponds to the number of input variables, in

this case the eleven sonic variables. The number of clusters that we instantiate is a hyperparameter that can

be tuned. Next, all points are assigned to one of these centroids to form clusters. A point is assigned to its
྘ closest centroid according to Euclidean distance. The cluster centroids of these new clusters is determined

and the process repeats.
