7.3     Fuzzy Synthetic Evaluation for Basic Rules

The main challenge of the judging process is that we can obtain different results
using different criteria. If we want to obtain a unique answer, we have to com-
bine criteria to get a new, unique criterion. The relative importance of the crite-
ria is hard to determine. Since we have no other information, we implement a
fuzzy synthetic evaluation (FSE).[11] FSE is a multiple-criteria-decision-making
method. It can determine the weights of each criterion based on the data only.
One way to determine the weights is the coefficient of variation method. If crite-
rion can differentiate the rules evaluated, the method will assign a large weight
to the criterion. We use this technique to analyze the performance of each rule.
