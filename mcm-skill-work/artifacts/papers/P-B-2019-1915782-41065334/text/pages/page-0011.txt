6.1.1   The Algorithm of the Loading Model
    3D-RSO algorithm is a heuristic residual space optimization algorithm, which
does not need additional preprocessing and optimal solution search operation in
the solution process, and can achieve an optimal solution with minimal compu-
tational consumption. Compared with other algorithms at the present stage, this
algorithm has obvious advantages in solving efficiency[2].
