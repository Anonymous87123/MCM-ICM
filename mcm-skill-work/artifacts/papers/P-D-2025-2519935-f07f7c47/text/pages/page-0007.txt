                                                                                4 Multi-layer Transportation Network Model

                                                                                    Baltimore can be abstracted as a multi-layer Arc-Node grid model, which represents the
                                                                                transportation network with a topological structure [2]. The core concept of the Arc-Node
                                                                                model is to approximate real-world road curves with a series of straight line segments [3]. The
                                                                                entire transportation network consists of nodes and arcs, represented as a graph G = (N, A),
                                                                                where N denotes the set of nodes and A represents the arcs. This is formally defined as:
