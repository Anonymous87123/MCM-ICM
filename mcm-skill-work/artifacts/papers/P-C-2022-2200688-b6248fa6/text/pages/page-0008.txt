    For the Change-point Selection in Prophet model, before introducing the changepoint, it is important
to introduce the Laplace distribution, which has a probability density function as follow:

                                     𝑓 (𝑥|𝜃, 𝑡) = 𝑒𝑥 𝑝(−|𝑥 − 𝜃|/𝑡)/2𝑡                                  (16)
where 𝜃 denotes the location parameter and t > 0 denotes the scale parameter. The Laplace distribution
is somewhat different from the normal distribution. In the Prophet algorithm, it is necessary to give the
location of the variable points, the number of them, and the rate of change of the growth. Therefore,
there are three more important indicators, namely:

   1. changepoint-range

   2. n-changepoint

   3. changepoint-prior-scale

Changepoint-range refers to the percentage of variable points that need to be set in a time series as long
as the previous changepoint-range, in the default function changepoint-range = 0.8, n-changepoint refers
to the number of variable points, in the default function is n-changepoint = 25. changepoint-prior-scale
indicates the distribution of the growth rate of changepoints. [4]
