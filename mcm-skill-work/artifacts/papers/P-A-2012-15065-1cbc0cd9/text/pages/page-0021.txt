5.3.1 Simulation of the tree in computer

In order to simulate the branching structure of this tree, we need to know the angles
(θ1, ф1, θ2, ф2) of transformation stated in model 2.2. Since there are no empirical
data for these parameters, we need to conduct a field measurement. The major
difficulty is to determine the direction of our imaginary x-axis and y-axis: a wrong
direction of coordinates will result in wrong angles and hence a twisted shape of tree
profile.

In our measurement, we first set the trunk to be z-axis, and the origin is at where the
z-axis touches the ground (our xy-plane). We equally divide the ground using 32
outgoing rays. (See illustration below)




Setting each outgoing ray as x-axis, we then have 32 possible coordinate systems. In
each coordinate system, we can directly measure and calculate a data set of (θ1, ф1,
θ2, ф2) by measuring the angle of the branches. We simulate trees using each of
these 32 data sets; compare the simulated vector tree with the real tree profile. The
one that matches the real tree most closely will be chosen. The data we get from this
field measurement and simulation is: θ1=π/12.5, ф1=π/3.7, θ2=－π/6, ф2=π/4.8

The total number of branches of our simulated tree is 2 9, and we assume that the
function d(I) defined in section 2.2.3.2 which determines the spacing of leaves
follows the Gaussian distribution with parameters(μ=0.1, σ=0.1).

We classify the shape of this tree leaf as Elliptic, and its average transverse diameter
is around 5cm. For simplicity of calculation, we represent the leaves using rhombuses
with average longer diagonal 0.25 in our computer simulation.
