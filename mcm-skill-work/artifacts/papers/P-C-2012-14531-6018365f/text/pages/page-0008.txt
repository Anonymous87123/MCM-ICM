2.2.2    Gradient descent
   The cost function J(θ) is minimized by using the algorithm of gradient descent,
which always drives θ down the locally steepest slope, in hope to reach the global
minimum of the cost function.
   At every iteration before convergence, new θ is replaced by the old θ as
