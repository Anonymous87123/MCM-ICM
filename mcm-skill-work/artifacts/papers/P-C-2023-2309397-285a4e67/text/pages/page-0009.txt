3.3 Interval Prediction Based on Bootstrap Method

The Bootstrap method is an important method used in statistics for interval prediction,
which first assumes that the data set obeys an unknown distribution, and later estimates
the distribution interval of the sample by repeatedly sampling the given data set [7].We
took the data predicted under the weighted combination model for the next 60 periods
as the sample set, after which we sampled it 1000 times with put-back to obtain the
1000 Bootstrap sample set，YB=(Y1，Y2，……，Y1000).
