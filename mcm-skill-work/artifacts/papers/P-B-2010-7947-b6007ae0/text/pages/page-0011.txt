3.3    Model Performance Metric

There exist two commonly used metrics for the evaluation of the performance
of a geographical profiling method. The first measure is the error distance,
which is the Euclidean distance between the most likely exact location of
the next crime and the actual next crime location [8]. The second measure
represents how much of the prioritized search area would need to be searched
in order to find the next crime location [12, 7].
    Our model evaluation metric should reflect how useful these models
would be to a law enforcement agency tracking a serial criminal. The most
likely exact location of the next crime is not very valuable to law enforce-
ment agencies, since often they are concerned with finding an area to search
and not a particular point [12, 14, 7].
    Thus, we consider the following metric that represents how much of the
prioritized search area would need to be searched in order to find the next
crime location, which we call the hit score. Given a geographical profiling
method with associated probability function P and a known next crime
location xn+1 , we wish to determine the hit score H.
