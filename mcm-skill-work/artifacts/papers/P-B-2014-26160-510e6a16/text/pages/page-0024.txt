 Figure 10. Comparison between ranks considering coaching start time or not of basketball
      In Figure 10. the horizontal coordinate represents rank that has not considered
coaching start time. The vertical coordinate represents difference with previous rank.
From the difference value between ranks considering coaching start time or not, we
can easily find that time has effects on college coaches’ ranks. What’s more, time
criteria has more effects on coaches whose rank is behind, while it has fewer effects
on coaches whose rank is front.
     To examine above conclusion, we use football coaches’ data to verify the results,
which are shown in Figure 11. It’s obvious that former conclusion is right.
