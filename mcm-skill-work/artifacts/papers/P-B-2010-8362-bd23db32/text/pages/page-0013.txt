    The main idea driving the algorithm is the idea that any point p can be assigned
a relative “criminal location probability” by taking the sum of some function (men-
tioned in Metrics and Functions) of the distances between p and prior incidents. It
might help to imagine this as the sum of non-canceling “gravitational pulls” of the
various locations: any point with a comparatively high total gravitational pull is going
to be near many of the crime scenes, and therefore should rightly be assigned a high
criminal location probability. Furthermore, the actual strengths of the pulls from
each point can be weighted depending on its recency, allowing for the algorithm to
more quickly adapt to the changing habits of the criminal. We will currently treat all
weights as equal to one, but we will discuss weighting in more detail in Time Coupling.
