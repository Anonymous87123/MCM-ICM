ັ 3.3 Tobit Model
    The Tobit model accounts for censorship by predicting a latent variable, y∗, instead of directly predicting the
observed variable y with the given predictors and previous data. The values y∗ and y are related as follows:

                               0 if y∗ ≤ 0,
                       y = y∗ if y∗ > 0.

The Tobit model attempts to predict the uncensored data itself given only censored data. This fits the framework
of Olympic medal counts since, as discussed, zero medal counts can be thought of as censored data. The Tobit
model assumes this relationship can be captured from the predictors linearly with the equation

                                                          y∗ = Xβ + ϵ

Where X is a matrix with the predictor data and β is a column vector of coefficients (so Xβ is some linear
combination of the predictor variables) and ϵ is an error term which is normally distributed with variance σ2.
