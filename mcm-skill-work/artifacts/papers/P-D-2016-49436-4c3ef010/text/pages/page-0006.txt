3.1.4 Edges
      Edges in our model also have several attributes. As we assume that the

communication is directed, an edge should indicate its start node and end node. In
reality, different kinds of communication tools have different efficiency, so the edge
also need to indicate its time which people should spend on transmitting information
through this edge. Because we assumed that pieces of information have same sizes, the
time spent on certain edge is the same for all information. In addition, the time of an
edge include all the time from the start node’s reception to the end node’s reception.
Thus we define our edges in our models as

                                     U  {u1,u2,u3,...,uk ,...}
                             u  edge{startnode, endnode, time}
     where k  N, startnodeV, endnodeV, startnode  endnode and time  0.

users, which represents mass communication. Also, people forward news in the Internet,
