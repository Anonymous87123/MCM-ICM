Hidden Layer -- This layer has one neuron for each case in the training dataset. The
neuron stores the values of the predictor variables for the case along with the target
value. In this case, there are 10 neurons in this layer.
Decision Layer -- This layer divides the value accumulated in the numerator
summation unit by the value in the denominator summation unit and uses the result
as the predicted target value.
