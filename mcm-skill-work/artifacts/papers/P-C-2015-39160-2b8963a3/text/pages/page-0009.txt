3.4.2 Changes in Initializing the Model
The only change from our initial phase initialization is that we now initialize each Person instance with a
default starting value of 0.5 for satisfaction, unless that Person is a placeholder representing an empty
position, in which case it is assigned a satisfaction level of 0.
