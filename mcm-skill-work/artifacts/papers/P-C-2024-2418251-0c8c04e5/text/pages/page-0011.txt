ྐ 4.3 Principal Component Analysis (PCA) Dimensionality Reduction
    In tennis, physical ﬁtness consumption is also an important reference standard. However, the consump-
ັ tion of physical ﬁtness cannot be quantitatively characterized into momentum points. Therefore, we extract

the running distance for each game of the athletes in the dataset separately to obtain a feature column of the
athlete’s running distance per game. This is then incorporated as a reference into the momentum model.
    Since there are already four feature vectors, and with the introduction of running distance, there are now
ﬁve input features in the model. Therefore, we perform Principal Component Analysis (PCA) to reduce the
data dimensions, coupling the ﬁve features and extracting the main input features to construct the model.
