4.6.1 Price Forecast
      In the original model we use the factor values of day t to determine whether a trade is to

be made on day t + 1 . To further maximize the asset, we introduce a price prediction model that
uses the factor values on day t + 1 to determine whether a trade is to be made on day t + 1 . We
use the LSTM model for price prediction, which is calculated as shown below.

  (1) First, the input gate value and the input cell candidate state value are calculated.

                 It = (LI *( Xt , yt−1) + bI ); At' = tan y(Lc *( X t , yt−1) + bc )  (21)

(2) Then calculate the forgetting gate activation value and cell state update value at the

moment of time.

                 Ft = (LF *( Xt , yt−1) + bF ); At = It * At' + F * At−1              (22)

(3) Finally, the value of the output gate is calculated.

                 Qt = (LQ *( Xt , yt−1) + bQ ); yt = Qt * tan y( At )                 (23)

to compare the effect, as shown in Figure 11.
