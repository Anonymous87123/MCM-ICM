3.3 Multi-Scale Geographically Weighted Regression (MGWR)

Multi-scale Geographically Weighted Regression (MGWR) is an advanced spatial analysis tech- nique that extends the traditional Geographically Weighted Regression (GWR) framework. Unlike GWR, which assumes a single bandwidth for all covariates, MGWR allows for different spatial scales (bandwidths) for each covariate, offering a more nuanced understanding of spatial relationships. This flexibility makes MGWR particularly suited for complex spatial datasets where relationships vary across space and at different scales. The MGWR model can be expressed as follows:
