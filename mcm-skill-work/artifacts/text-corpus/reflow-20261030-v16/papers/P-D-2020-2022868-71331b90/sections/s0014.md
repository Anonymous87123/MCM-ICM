9. Algebraic Connectivity

Algebraic connectivity ˜λ2 is a standard network metric based on the size of the second smallest eigenvalue of the Laplacian matrix associated with the network. The Laplacian matrix is deﬁned as the diagonal matrix containing the degrees of each node minus the adjacency matrix. A lower ˜λ2 indicates the network is close to splitting into two distinct subnetworks while a higher ˜λ2 suggests greater overall cohesion.
