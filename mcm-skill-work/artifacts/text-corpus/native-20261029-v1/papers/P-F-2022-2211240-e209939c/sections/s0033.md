Weaknesses

• Our equity index is a composite score, which means that we can only get an overall picture of equity, not the speciﬁc structure. We can further improve the model so that it can reﬂect the development of economy, technology and ecology respectively. • When we analyze the impact of asteroid mining on the equity of countries, we act the changes on the superior indicators rather than the more basic inferior indicators. We could further reﬁne the model by making changes directly to the inferior indicators, which would be more in line with reality. • For simpliﬁcation, we used second-order difference equations to ﬁt the develop- ment process, which may deviate from reality. In the future, we can use differ- ential equations of higher order or use Markov chains for prediction to improve the accuracy.
