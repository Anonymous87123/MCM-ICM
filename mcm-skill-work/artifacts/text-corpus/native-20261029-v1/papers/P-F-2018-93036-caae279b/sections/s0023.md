Model Exposition This section presents the PI model. The backbone of the demand model is a finite mixture of agency types, each of whom has demand over PI providers.

First, each type enjoys a flow utility djθ from buying from person j and a time utility njθ from transacting with person j; meanwhile the utility is normalized to zero.
