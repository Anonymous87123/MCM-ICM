Sensitivity to Number of Cars in the System

In order to determine the eﬀect of number of cars in the system, an eﬃciency was deﬁned for the system, such that efficiency = cars out of system this tick

. If this is summed over all of the ticks, one gets an accumulated cars in system at start eﬃciency, a sort of measure of how well the system is performing over time.

From this, we see that there seems to be a fairly consistent drop oﬀin accumulated eﬃciency for every step up in the number of cars. Thus we can feel conﬁdent that our model is not artiﬁcially hampering itself based in relation to the number of cars in the system, and our method of normalizing over the populations is valid in our metric deﬁnition.
