2. Sigmoid function

Sigmoid function is a good threshold function. It can be used for normalizing popula- tion, per capita grain yield, etc without an apparant limit.

f(x) = 1 (10) 1 + e−b(x−xmin)

Where, xmin is the minimum value of the index, and b is used to control the rising speed of the function.
