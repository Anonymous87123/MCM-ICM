5.2 Target Selection

In addition to the obvious economic functional value of harvested wood, forests also have a strong functional value of ecosystem services. In order to further explore the influencing factors of value assessment, the forest ecosystem service function value assessment system is listed, as shown in the following table.

Service function types water conservation soil conservation carbon sequestration nutrient accumulation air purification biodiversity conservation forest recreation

Specific contents regulate precipitation and evaporation, etc. protect fertilizer, stabilize soil, etc. sequester carbon, release oxygen, etc. accumulate elements like N, P, K, etc. absorb SO2, hold dust, eliminate pollution, etc. protect capital investment and opportunity cost, etc. tourism income, investment, travel expenses, etc.

Some studies have pointed out that the natural logarithmic transformation of the value of forest ecosystem services can reduce the difference, volatility and asymmetry of the original data to a certain extent, thereby reducing the value offset and improving the fitting accuracy of the model. Based on this, the regression model we constructed is as follows:

(10) ln 𝑦= 𝑢+ 𝑏 𝑡𝑦𝑝𝑒 × 𝑋 𝑡𝑦𝑝𝑒 + 𝑏𝑖 × 𝑋𝑖 + 𝑣

where y is logarithmic vector of values of forest ecosystem services, 𝑋 𝑡𝑦𝑝𝑒 𝑎𝑛𝑑 𝑋𝑖 are independent variable matrices; 𝑏 𝑡𝑦𝑝𝑒 and 𝑏 𝑡𝑦𝑝𝑒 are independent variable coefficient matrices; 𝑢 and 𝑣 are constant term and residual term respectively. Among the independent variables, 𝑋 𝑡𝑦𝑝𝑒 is the forest ecosystem service function type variable, 𝑋𝑖 includes population variable, economic variable, and forest area variable.
