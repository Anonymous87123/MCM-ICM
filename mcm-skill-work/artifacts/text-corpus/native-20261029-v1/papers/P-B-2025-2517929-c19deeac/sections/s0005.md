1.4 Our Work

This task requires us to construct an optimized model for sustainable tourism with univer- sal applicability, which mainly includes:

1.

Construct a multi-objective optimization model with the goals of maximizing fiscal revenue, minimizing environmental damage, and maximizing resident satisfaction.

2.

Solve the model using the NSGA-II algorithm and select the optimal combination of sustainable tourism measures.

3.

Based on the benefit magnitudes of decision variables, construct an expenditure-feed- back model for additional revenue.

4.

Conduct a sensitivity test using the local perturbation method and analyze the im- portance of variables.
