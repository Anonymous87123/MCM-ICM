4.3 Comparison of Model 1&2

In this part, we will compare the results of Markov model and long-term differential model to ensure the model is applicable.

According to formula (35), we get the distributions of each language in each country. To sum up all columns of matrix diag(Nt)*H, we will get the number of total speakers in tth period, namely the predicted number of each language in tth period. Let t=50, the resultis,
