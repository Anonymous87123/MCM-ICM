6.2 Weaknesses

●Due to time and data constraints, the model fails to considerate the differences within urban or rural areas. ●In the process of calculation, the data that can not be found in some areas are replaced with the previous data. ●Rather than strictly considering the difference in the number of charging piles in charging stations in different regions, the number of charging piles in the same type of charging station is considered to be the same.
