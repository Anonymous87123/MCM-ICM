4. The indicators we have identiﬁed can eﬀectively and reasonably reﬂect global equity.

Justiﬁcation: There are many indicators that can reﬂect global equity to a certain extent, and diﬀerent indicators also interact with each other. It is impractical to enumerate all the indicators that aﬀect global equity in detail, and it will also bias the model, so only a limited number of indicators can be selected.
