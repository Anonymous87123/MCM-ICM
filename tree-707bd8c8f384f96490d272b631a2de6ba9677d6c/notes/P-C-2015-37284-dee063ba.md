# P-C-2015-37284-dee063ba — distilled rules

- The caption side is a property of the exhibit class, not of the drawing: all 20 figure captions in this paper print below the drawing and all 5 table captions print above the grid, and each case was settled by searching the caption head in the text layer and comparing its y against the region box - never by assumption [caption.position]
- The caption noun does not name the family - 'pie of the whole model' is a pie, not any chart family, and 'network of loyalty' is a node-link drawing only because the crop shows circles and edges; call every family from the crop [geometry.family]
- A diagram that prints its own formula symbols (alpha-1..alpha-6 on nodes, beta-15 on edges, t_ik on arrows) is data_labels true with printed_numbers false: symbols are labels, not measured values [geometry.data_labels]
- printed_numbers turns true only when real measured values are printed inside the drawing - Fig 9 carries 1.05, 1.02, 1.03, 1.07 on its edges and 0.95, 0.92 beside its nodes with no axis anywhere, and that still counts [geometry.printed_numbers]
- Slant alone does not make a figure three dimensional: two slanted planes drawn side by side are isometric, a vertical stack with a printed Time Stamp axis is isometric, but the left-to-right row of slanted panels in Fig 20 stays three_d no - orientation decides [geometry.three_d]
- Book one row per measured region: a four-panel figure measured as two regions becomes two rows sharing one caption, and panel_count describes only what sits inside that region [geometry.panel_count]
- shared_axes is only for panels that genuinely share one x quantity - the matched cost charts printed on pages 16 and 17 are separate regions and separate rows, so neither claims shared axes [geometry.shared_axes]
- A one-entry legend that merely repeats the panel title ('total cost', 'Indirect cost') is still booked outside-right, because the field records where the box is drawn, not how much it tells the reader [geometry.legend]
- Table width follows the grid: the two-column lookup tables are half width while the six- and seven-column ledgers run full width [table.width]
- A table can stand in for a legend - the index-meaning table decodes the chromosome alphabet that Figures 11 and 12 draw, so its rows have to be read with those figure rows [table.text_cols]
- A printed gap is not a zero: the two cost cells in the total row of Table 3 are left empty and that emptiness is itself data, so record it in the note instead of counting the row as complete [table.rows]
- An exhibit nobody names keeps first_page null with count 0 and null gap_sentences; only a printed sentence that names or points at the exhibit earns a first_page [mention.first_page]
- The layout's section can be wrong when a figure sits above the heading that follows it: Figure 3 prints at the top of page 5 under section 3.3 but illustrates section 3.2, so the place is overridden at spec level when the crop contradicts the layout [place.section_path]

### 三处判断

1. **题注方位是测出来的**：逐个把题注前 4 个词在 PDF 文本层里 `search_for`，与区域 bbox 的 y 比较——20 张图全部在下、5 张表全部在上，不是照惯例假定。
2. **布局把图 3 归档到 3.3**：图 3（岗位树）印在第 5 页页首、紧随其后才是 3.3 标题，但画的是 3.2「The network among position」的内容，故在 spec 层把 place 覆盖为 3.2。
3. **三个 other**：图 11（注释染色体串）、图 12（遗传算子符号示意）、图 14（无比例饼图）在族词汇里没有对应项，均记 `other` 并写 `other_note`，不硬塞进邻近族。

- 图 1、图 3、图 7、图 11、表 4、表 5 正文中无人点名，按语料先例记 `first_page=null / count=0 / gap_sentences=null`，不编造指向句。
