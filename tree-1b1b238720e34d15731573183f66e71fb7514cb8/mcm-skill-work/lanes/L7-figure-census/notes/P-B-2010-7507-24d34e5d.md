# P-B-2010-7507-24d34e5d — distilled rules

- 本题型用一套固定模板反复出图：上图是平面热图（喷流色表 + 右侧色标 + 图内图例），下图是同一密度场的三维曲面，两图共用一个题注、(a)/(b) 标在图上而不写进题注 [geometry.panel_layout]，[geometry.colorbar]。
- 热图一律带色标且色标顶端印科学计数倍数（x 10^4 / x 10^-3），题注不再重复数量级 [geometry.colorbar]，[caption.words]。
- 图内图例固定放在右上角白框里，条目只有 Crimes / Next Crime 或 Cluster / Centred，map 面板则用 Rape/Burglary/Residence [geometry.legend]。
- 题注极短（4-14 词），只写「谁 + 哪个模型 + (a)(b)」；数值结果（effectiveness ratio）写进图内标题，因此题注不下结论 [caption.words]，[caption.concludes]。
- 同一题注被复制时连犯人不改：Figure 6、Figure 7 的 (b) 子标题仍写 Offender C，可从图内标题与题注的矛盾看出 [caption.verbatim]。
- 算法用纵向流程图上而下走，框形分工固定：矩形=端点，椭圆=处理，六边形=循环，循环箭头用紫色单线回指 [geometry.panel_layout]，[geometry.data_labels]。
- 聚类结果先给树状图（叶节点用案件编号），再给轮廓值曲线选簇数，最后给四色散点展示分簇，三步固定顺序 [geometry.family]。
- 引用几乎全是括号回指 (see Figure N) 或 is shown in / is seen in 的顺叙，只有三处用 Figure N is/ displays 作主语 [mention.lead_pattern]。
- 第三章之后图全部落在结果小节（7.2、8.2、9.1），算法图落在方法小节，指标体系图落在度量小节 [place.section_kind]。
- 图为版心内单栏宽度（120-360 pt），成对图竖排占半页，没有一张图独占整页 [place.area_frac]，[place.solo_page]。
- 全篇只有一张表，三列（犯人 + 两个统计量）、竖线分隔、无表题、无表注，数值居中不对齐小数点 [table.rule_style]，[table.decimal_aligned]，[table.note_sentence]。
