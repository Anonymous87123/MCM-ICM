# P-A-2010-7920-06d31c2b — distilled rules

- 本题型的图分两套模板：手绘线稿只带一个 Figure N 标签（词数 2），软件图只带图框内的标题和一个 Graph X 侧标，两套都不写整句题注 [caption.words]，[caption.position]。
- Figure 标签一律压在线稿下方，Graph 标签一律在框外右侧或左下，标题则压在框顶——标签位置由谁生成决定，不是由作者排版决定 [caption.position]。
- 软件图的坐标轴文字用竖线当单位分隔符（v_f | m/s、I | kg m2），单位写在轴文字里而不写进题注 [caption.units]。
- 图框内不放图例：单曲线图靠标题自明，三维图靠深浅着色标出可行域，没有色标 [geometry.legend]，[geometry.colorbar]。
- 整个灵敏度一节用同一句式引出每张图：When the final velocity was tested against the X of the bat, the following graph was produced [mention.lead_sentence]。
- 图后一句解释一律是 As the X increases, so does the final speed 的因果直陈，再点出敏感的强弱 [mention.trail_sentence]，[mention.read_sentences]。
- 只有三维图给参数扫描面（初速 x 角速度），用阴影域表示约束后的可行组合，其余五张都是单变量一维曲线 [geometry.three_d]，[geometry.panel_count]。
- 章节分工：两张受力线稿放在 Model A 概念节，单幅曲线放在 Model B 推导后的检验处，形变三联线稿放在 Discussion，一维参数扫描全部集中在 Sensitivity Analysis [place.section_kind]。
- 正文引用这些图不用编号而是用指示语（the following graph、shown below、the second frame of Figure 3），全篇没有一次 Figure N shows [mention.lead_pattern]。
- 线稿的标签直接写在图下方且与图同区，因此正文里 Figure 1 会出现在句子中间（struck by Figure 3 a baseball），引用位置落在词流里而非句末 [mention.style]。
- 版面：所有图都不独占页，最大的三维图占 0.15 版面，其余 0.02-0.13 [place.area_frac]，[place.solo_page]。
