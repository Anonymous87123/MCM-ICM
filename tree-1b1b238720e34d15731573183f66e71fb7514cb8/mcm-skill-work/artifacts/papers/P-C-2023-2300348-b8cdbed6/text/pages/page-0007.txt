4.1 Description of GRU Algorithm

    GRU (Gated Recurrent Unit) is a type of recurrent neural network (RNN) that is commonly
used for time series analysis. It has similar properties to the LSTM (Long Short-Term Memory)
architecture but is generally faster to compute.

    The main idea behind the GRU architecture is to have two gates, a reset gate and an update gate,
which control the flow of information through the network. The reset gate decides how much of
the previous hidden state should be forgotten, while the update gate decides how much of the new
input should be added to the current hidden state.

The update equations of GRU are as follows:

                rt = σ (Wirxt + bir + Whrht−1 + bhr)

                zt = σ (Wizxt + biz + Whzht−1 + bhz)                     (1)

                h˜t = tanh (Winxt + bin + rt ∗ (Whnht−1 + bhn))

                ht = (1 − zt) ∗ h˜t + zt ∗ h(t−1)

where:

                Symbol                               Decription

                   zt                             the update gate
                   rt                              the reset gate
