     4.1.2 Statistical Tests

         • Normality Test:GDP and medal count distributions were validated using the
            Shapiro-Wilk test (p > 0.05).

          • Residual Independence: The Durbin-Watson (DW) statistic was calculated as
             DW = 2.01 (95% CI: 1.98–2.04), falling within the range of 1.5–2.5, which sug-
             gests no statistically significant autocorrelation in residuals (p = 0.32 via Durbin-
             Watson test).
