5.1 Introduction of Current Situation

We chose to study the Baltimore bus system project.
    Using the previously-constructed transportation network model, we incorporated data on urban

architecture and the overall layout of Baltimore’s bus system and generated Figure 10. The city’s
bus stops and routes are radially arranged. In-depth analysis reveals that many residential areas lack
nearby bus stops as routes mainly run along main roads instead of reaching into these areas. This not
only restricts residents’ convenience in using public transport but also fails to fully satisfy their travel
demands.
