      Solution 5.1.4: Descending Striped Flight Path
A Brief Description:

This solution simulates a plane systematically eliminating stripes of the search area
with straight paths. We can then compare straight path searches to random path
searches and begin to draw conclusions on the most effective solution.

How It Works:
