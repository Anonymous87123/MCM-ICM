5.4 Error Analysis

We use error analysis to measure the confidence of the model prediction. The smaller
the prediction error, the higher our confidence in the model we build. By reviewing the
literature[10], we determined to use the mean absolute error (MAE), the root mean
squared error (RMSE) and the coefficient of determination (R2) to evaluate the
effectiveness of the model prediction.

⚫ Mean absolute error (MAE)
MAE is the weighted average of the absolute values of the differences between the

predicted ( ) and true values ( ) of the model. Mean absolute error does not consider

the direction of the error, but only the average error magnitude of the predicted value.
Therefore, this indicator can avoid the problem of mutual offset, and then can reflect
the size of the actual prediction error more accurately. The range of MAE is [0, +∞),
and the smaller the MAE is, the better the model fitting. The formula is as follows.

RMSE is the average root of the expected value of the square of the difference between
the true value and the predicted value. It measures the deviation between the predicted
and true values and is more intuitive in terms of order of magnitude. The range of the
RMSE is [0, +∞), and the smaller the RMSE value, the better the model's predictive
