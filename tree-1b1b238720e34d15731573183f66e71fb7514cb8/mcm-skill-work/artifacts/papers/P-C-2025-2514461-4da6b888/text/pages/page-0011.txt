                                                                                5.3 Baseline: LSTM model

                                                                                5.3.1 Model Overview

                                                                                 ྘ In this section, a baseline LSTM model was built and trained using Pytorch. The model

                                                                                took as input all the gold / silver / bronze medal counts of all countries before the 2024 Games,
                                                                                and was fitted to the medal counts in 2024. For the loss function, instead of the typically-used
                                                                                MSE loss, we added a punishment term, punishing deviations of the sum of medal counts of all

                                                                                ଆ countries for a certain discipline from the discipline’s known event count. In the predict step,

                                                                                all past years’ data were fed into the model to predict the medal counts for all countries in all

                                                                                ࿐ disciplines. Summing up the disciplines, we yielded the medal count for all countries.
