6.1.2 The model construction

There are lots of classical epidemic models, such as SI, SIS, SIR, IC and LT. We

take into account the central node (such as the Internet) has higher spreading function

than ordinary spreader. We then introduce super-spreaders to our network to improve

the SIR model. We divide the user into four parts: ignorant, spreader, super-spreader
and immune. And the definition of these are as follows[11]:

                              Table 3 Four type of users
