3.1.1 Applying POD to the dataset

    For all data points corresponding to a certain time record, we call these data points
a snapshot. A snapshot contains the longitude and latitude data as well as sea surface
temperature of all data points at that time. We can express a snapshot in this way:

                            ⃗i = [d1 , d2 , d3 , ..., dn ] = SST (⃗x, t)

where each vector S ⃗i is a snapshot which contains n data points (in this case n=17 ×
40=680). It can be expressed as a term related to both location ⃗x and timet. The whole
dataset is a matrix which composed of m (here m = 468) row vectors (snapshots).
     The goal of POD is to decompose every snapshot into the following forms:
