3.4     Caloric Intake—The Basal Metabolic Rate
If dragons are anything like Earth’s creatures, then its basal metabolic rate per unit mass will decrease
as it gets larger. This means that although it will need more calories as it grows larger, it won’t be
directly proportional to its size.

3.4.1    Metabolic Rate and Size
A classic example is that a mouse burns many more calories per unit mass than an elephant does.
Studies have shown that if M is mass, then BMR/M ∝ M−1/4

day. An elephant, which is about 3,000 kg would be expected to burn only 8.82 kcal/kg per day.
