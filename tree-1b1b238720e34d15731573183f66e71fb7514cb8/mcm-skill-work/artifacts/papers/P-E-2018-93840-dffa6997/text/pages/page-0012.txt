Figure 3: This gure is a parametric plot of (s; r), where s and r are expressed as a function of t. The s r curve

represents the occurrence of a saddle-node bifurcation. In the Stable State, there is only one equilibrium; in
Vulnerable State, there are three; in Fragile State, there is one.

    This graph is crucial to analyze a country's fragility state. As long as we obtain the enough
information on each required parameters for a country, we can convert the data to (s; r) using our
composite index. Thus, we can immediately tell the current state of that country using this graph.
For further application of this graph in the real world, we have conducted three case analyses in
the next section.
