## assumptions — 2 General Assumptions and Justifications (pp. 6-6, 8 blocks)

`route → limit → limit → limit → limit → limit → limit → limit`

Seven assumptions, one measured block each (the fifth is split at a line break), and the section promise that 'each of our assumptions is justified' is not kept - no block has a justification sentence. The assumptions are: people control the supply of their PI; PI is valuable and quantifiable; different people, domains and combinations have different values; market law governs PI once traded; government regulation is mandatory and effective; society trends toward sharing; a leaked PI becomes part of an identity-theft ring. The fourth and fifth together do the real work, because the national model is a Bayesian game under exogenous price bounds plus exogenous correction factors for policy - i.e. regulation is assumed effective, then its effect is calibrated by a free parameter. The last assumption is the one that turns a leak into an absorbing state and justifies the liability argument in the memo.

## model-establishment — 3 Data sources and variable description (pp. 6-8, 3 blocks)

The data chapter is two paragraphs and a 17-row variable table. The sourcing story is unusually candid: the authors wanted the Acquisti FERPA/EEOC dataset, found it too small for their variable set, and switched to 'some of the data that is already in McSherry' - i.e. the model is calibrated on a mixture of published aggregates and simulated data, which the examination chapter later admits. ## model-establishment — 4.1 Individual pricing: features, AHP+entropy weights, TOPSIS, consistency, subgroups (pp. 8-12, 27 blocks)

`route → route → source → source → source → route → define → source → source → derive → read-figure → read-figure → source → derive → read-figure → read-figure → derive → define → read-figure → read-figure → derive → read-figure → read-figure → route → source → read-figure → read-figure`

The individual model is a standard multi-criteria pipeline and the paper is honest about the pipeline, less so about the choices inside it. Six personal features (name, gender, age, education, income, occupation) and four domain feature sets (social media activity counts, financial accounts and credit, hospitalisation and condition, e-commerce preferences and purchases) are selected by citing 'the most cited' paper in each field - a selection rule, not a validation. Weights combine AHP (subjective) with entropy (objective) by a convex combination whose alpha is never given a value, so the reported weights in Fig.3 cannot be reproduced. TOPSIS then scores each individual against ideal and negative-ideal points, and the 'consistency tradeoff' term adds a correction for combinations, defined as a ratio of weighted indicators with an exponent that is stated in the figure only. The output is a per-person price distribution in four domains (Fig.4) and a total (Fig.6); no price is quoted in the text, so the reader cannot check a single number. The subgroup chapter classifies people by a multiway tree over age, occupation and income, and the classification is imported from a distributed-systems reliability paper - the method is cited, the parameter choice is not.

## model-establishment — 4.2 Group pricing: risk perception and Markov value dynamics (pp. 12-15, 21 blocks)

`route → define → define → define → derive → derive → define → interpret → read-figure → derive → derive → derive → interpret → read-figure → define → derive → derive → derive → define → read-figure → read-figure`

The group model is the paper's most ambitious and least identifiable piece. Risk perception is a product of five terms: privacy type (an exponential of the consistency tradeoff), generational difference (a Gaussian in mean age centred at 27 with a stated standard deviation), network effect (a logistic in year, cited to an autologistic wildlife-distribution paper), data breach (a disclosure degree), and subgroup difference (a ratio of leaked to total). Only the generational term has a functional form with a visible rationale - a bell over age - and even that is fitted to nothing. The five terms are multiplied with no argument for multiplicative separability, and every coefficient inside is an uncalibrated constant. The Markov layer is cleaner: six value states from 'very reluctant' to 'very willing', initial matrix given, transition matrix computed by Bayes (the matrix itself is in a figure, not the text), then the state recursion. The output is Fig.10, a price by age band, and the claim that middle-aged groups have the highest PI value - which is plausible but is a property of the assumed age-Gaussian, not an empirical finding.

## model-establishment — 4.3 Nation pricing: Bayesian game, policy and culture corrections, externality (pp. 15-19, 38 blocks)

`route → define → define → derive → derive → derive → interpret → route → define → define → define → define → route → derive → define → derive → define → derive → define → derive → define → define → define → interpret → route → interpret → interpret → define → read-figure → read-figure → route → define → define → define → derive → derive → derive → derive`

The national model is a static Bayesian game with independent private values, uniform on [O_min, O_max] for buyers and on the reversed interval for sellers, and the equilibrium quotes are the textbook linear strategies g* = (2/3)b + (1/12)O_max + (1/4)O_min and s* = (2/3)d + (1/4)O_min + (1/12)O_max. The derivation is not shown, and the heterogeneity assumption - every buyer draws from the same interval - is what makes the closed form available, so the model's main result is an artefact of a distributional assumption the paper never justifies. The three policy corrections are then multiplicative or additive constants (T_mc an interval rescale, T_pp a scale on group value, T_cc a linear function of disclosure), and the cultural term is a linear combination of GDP, IT-industry share and mean years of education with four free coefficients - all of them unestimated. The headline result is 783: the price where buyer and seller curves cross in the simulation. That number is the paper's most quoted output and it is produced by a simulation whose lowest and highest market prices are set by the operator, so it is a chosen scale, not a measured price. The externality optimisation adds one correction coefficient to each of the three levels and is stated, not derived.

## model-establishment — 5 Risk model of PI (four domains, qualitative) (pp. 19-20, 14 blocks)

`route → route → route → define → route → define → route → define → route → define → route → derive → derive → define`

The risk chapter is qualitative until its last three blocks. Each of the four domains gets a paragraph of domain knowledge - social media (acquaintance/stranger split, group-specific harm), finance (identity theft, money laundering, fake shopping), health (dignity, HIV and virus flu, elderly targeted by device sellers), e-commerce (preference inference, price discrimination, professional embarrassment) - and the domain content is the paper's most concrete writing. Then Ri = sum of loss value times probability, with indices over domains, groups and risk types, and the answer to the human-rights task: risks that are psychological or social are 'human rights' risks, risks that are financial are 'property' risks, so PI cannot be classified as one or the other. That answer is the same one the memo gives and it is argued, not computed; the formula (30) is never filled with numbers. Note the elderly/young/middle-aged examples are asserted per group with no data behind them, and they are the only justification for the subgroup structure used in 4.2.

## results — 6.1 Examination using the real data (pp. 20-21, 3 blocks)

`route → check → compute`

The validation is one comparison: the model's predicted age-profile of willingness to share is compared with the Acquisti data, and the difference is reported as 'between 0 and 0.17'. That is the number the abstract repeats as 'the inaccuracy of our model is no more than 0.17' and the memo does not mention. Two problems are visible in the single block that reports it: the comparison is over a tendency index whose units are not given, so 0.17 is not interpretable without the scale; and the fit is reported for one dimension only (age), while the model has six personal features and four domains, so the examination tests a slice of the model and generalises to all of it. Fig.13 is the only evidence for the claim and it is not read in the text.

## sensitivity-analysis — 6.2 Error analysis, 6.3 Stability test (pp. 21-22, 5 blocks)

`limit → limit → limit → limit → check`

The error section lists three sources honestly: classification by demographics ignores within-group deviation; features may interact nonlinearly, which the linear weighting cannot capture; and risk perception calibrated on current values will drift as the information industry develops. The first two are real limitations of the AHP-entropy-TOPSIS pipeline and they are the paper's most accurate self-criticism. The stability test is a feature-substitution experiment: replace some features, re-run, compare, and the reported result is that the output is stable when a few features are replaced and changes markedly when many are - which is the expected behaviour of any weighted sum, not a robustness result. No threshold is given for 'a few' versus 'many', so the test cannot be replicated; the heading 'Strengths' is glued to the tail of block 230.

## strengths-limitations — 7.1-7.3 Strengths, weaknesses, future work (pp. 22-22, 8 blocks)

`ext:claim → ext:claim → ext:claim → ext:claim → limit → limit → handoff → handoff`

Four strengths, two weaknesses, two future-work blocks. The strengths are factor coverage, use of classical algorithms, the three-level architecture, and adaptability - all method claims, and the second is a claim that the paper follows its sources rather than that it validates them. The weaknesses are the interesting part: simplifications leave errors, and data for the cost of privacy are scarce so 'some models are only theoretical inferences and require data to test'. That second sentence is a direct admission that the national model's coefficients are free parameters, and it is the most honest line in the paper. The future work names the right fix - measure characteristic data, compare with reality, relax assumptions - and then adds a dynamic game, which would address the one-to-one static structure of the national model but not the calibration problem.
